# Kiva · 俯视探索 Demo

Bevy 0.20.1 / Avian 0.8 / Rust 单 crate 游戏，通过 Trunk / WASM / WebGPU 在浏览器运行，也支持原生桌面。
当前是带动作和双人格武器联动的竹林战斗原型：固定 16:9 俯视镜头、蒙皮愁铃客角色，以及可反复练习的敌人。
旧的 MOBA 游戏完整保存在 `lol` 分支，当前代码与素材已重新整理。

## 运行

需要 Rust 1.97.1 或更新版本：

```sh
rustup target add wasm32-unknown-unknown
cargo install trunk --locked
make run
```

浏览器打开 <http://localhost:3221>，等待加载后点击进入。需要支持 WebGPU 的浏览器和 GPU 加速。
本地使用 localhost，发布使用 HTTPS。游戏运行不需要 Node.js。
自定义端口：`make run ARGS='--port 8080'`。开发服务由开发者自行启动与关闭。

原生桌面使用 `cargo run --locked`，需要可用的图形环境。Linux 构建依赖包括
`build-essential`、`pkg-config`、`libx11-dev` 和 `libxkbcommon-dev`。

## 操作

| 输入 | 行为 |
|---|---|
| 点击进入 / 点击游戏画面 | 捕获鼠标，开始或恢复操作 |
| W / S | 沿当前视角前进 / 后退 |
| A / D | 相对当前视角向左 / 向右横移 |
| 鼠标左右移动 | 同步旋转人物朝向和相机方位 |
| Shift 点按 / 长按 | 闪避 / 衔接疾跑；松 Shift 继续跑，松开所有方向键停止 |
| Space | 跳跃；空中再按一次二段跳，落地恢复次数 |
| 鼠标右键 | 点按卸势：0.25s 正面免伤窗口，0.65s 冷却，长按不连发 |
| C | 切换蹲伏 / 起身；疾跑时按 C 滑铲，结束后保持蹲姿 |
| 1 / 2 | 切换长刀震击+狙击枪 / 长刀旋斩+火炮套装 |
| 滚轮 | 在同套装内切换哥哥近战 / 妹妹远程 |
| 左键 / Q | 普攻 / 切换锁定目标 |
| E / Tab | 起手技能 / 有效窗口内释放联动 |
| F2 | 切换靶子 / 实战模式，重新生成敌人；进入卡片也可选择 |
| 火炮模式鼠标上下 | 调整地面落点距离，不改变镜头俯角 |
| Esc / 切出窗口 | 释放鼠标并暂停；重新点击继续 |

镜头保持固定俯视角，人物身体中心固定在屏幕横向中间、纵向 2/3 处。
HUD 顶部显示锁定敌人的真实血量，底部居中显示玩家生命，右下角菱形技能显示可用状态、E 冷却和 Tab 联动窗口，并标出当前近远武器与套装。
鼠标上下移动不改变俯仰；斜向移动不会加速。50×50 米竹林包含战斗空地、曲径、竹海、岩石、落叶与蓝绿薄雾；竹干和岩石与显示共用碰撞几何。当前是“大雾幽篁”主题重建，原版完整地图布置尚未恢复。
出生点左后方是约 20° 的坡道和 1.5 米高台，右后方是约 2.6 米高的小山，包含可步行缓坡和测试坡度限制的陡坡。
角色与地形共用三维物理；起身前检查头顶空间，跳越低围墙后跌出场景会回到出生点。
默认靶子模式只有 1 个 1.45 倍愁铃客、100 万生命的静止敌人，不主动移动或攻击，仍可受伤、击飞和自然落地；实战模式为单个愁铃客镇守对战，使用从原作恢复的 P1/P2 决策池、权重和行动冷却，支持蓄势、出招、卸势破绽及转阶段。两阶段各 650 生命、命中范围和伤害是 Kiva 适配值，尚非原作完整复刻。
重刀震击将目标从起飞点击飞约 3 米，Tab 切到角色背后低位仰视镜头，短暂瞄准后狙击原目标，再回到俯视镜头。开枪伴随白金火光、弹道、镜头后坐和命中碎光，命中时世界短暂停顿约 50ms；网页端另有合成枪声、命中声和短回声。火炮跃进途中 Tab 衔接旋刀。角色、专属长刀和刀鞘来自本地燕云资源提取，狙击枪和火炮保留现有外观；竹林几何由程序生成。
身体已接986节点原骨架和35个原作动作：愁铃客长刀技能片段，以及原作共用卸势、跳跃三段与闪避；具名原轨按身体比例和Kiva时序适配。移动、蹲滑、枪姿等仍使用随包CC0动作回退。角色补充原混合图的粗糙度/金属度/AO，竹林使用原竹叶/竹皮/落叶图与自写PBR细节shader；原发丝/布料专用BRDF和完整原AI仍有缺口。
蹲行速度为 1.6m/s，蹲下 / 起身平滑过渡并通过腿部 IK 保持脚部落点；跳跃、闪避和暂停清理会退出蹲姿。
模型与武器跟随骨骼，位移、跳跃高度和伤害仍由模拟决定。资源来源及许可证见
[动画说明](assets/animations/README.md)和[角色资源说明](assets/choulingke/README.md)。

## 构建与检查

```sh
make check
cargo clippy --locked --target wasm32-unknown-unknown -- -D warnings
trunk build --release
```

`make check` 包含格式、原生 Clippy、Rust 行为测试、Node 输入生命周期测试和 WASM 编译检查，
测试需要 Node.js 22 或更新版本。普通测试覆盖控制方向、碰撞、步进、相机构图、骨骼采样、身体动作、武器挂点和浏览器输入桥。
它们不替代真实浏览器的手感和性能验收。

生产产物在 `dist/`，将该目录部署到 HTTPS 静态站点即可；反向代理需正确返回 `.wasm` 的
`application/wasm` 类型。部署到子路径时使用 `trunk build --release --public-url /子路径/`。

## 代码结构

- `simulation/`：固定 60Hz 的三维物理、支撑、动作、伤害和联动，无窗口可测试。
- `gameplay/`：关卡与实体装配，坡道、小山和地面由渲染 / 碰撞共享同一份几何。
- `client/`：设备输入、视角、插值、骨骼姿态、蒙皮角色、竹林显示和相机。
- `web/`：加载入口和浏览器鼠标捕获，游戏规则留在 Rust。

当前模型与竹林效果见[首次实测](docs/plans/choulingke-bamboo-arena.md)和[原动作、材质与单 Boss 对战](docs/plans/choulingke-source-behavior-and-rendering.md)。竹林为主题重建；原版镇守BGM仍待准确定位，当前攻击/命中/卸势使用自制程序音效，详见[声音状态](assets/audio/README.md)。

详细边界和执行顺序见 [架构文档](docs/architecture.md)，开发规范入口见
