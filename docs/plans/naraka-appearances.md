# 两套玩家外观

进入 / 暂停卡片选择外观，游戏中 F3 切换“愁铃客 + 长刀”与“无尘·李火旺 + 横刀·烛泪”。默认使用愁铃客。外观与 1/2 玩法套装、近远模式是独立概念；换装不改伤害、生命、技能、碰撞、相机或敌人身份，远程保留现有枪械。

## 数据与职责

`web/appearance.js` 在 WASM 启动前安装，按钮和可信 F3 只提交选择，Rust `AppearanceSelection` 保存客户端当前值。`appearance::reconcile` 在 Update 动画之前比较显示根的 `AvatarAppearance`，只替换该玩家自己的模型 / 调色板节点和两套近战武器的显示子节点。物理 actor、PlayerView、RigPose、BoneVisual 及其武器根保持原实体，不重新创建动作或播放时钟。暂停与引擎加载时选择可以保留至生效。

愁铃客继续使用 KIVAAV02 和现有原动作、材质。新增 `assets/lihuowang/character.bin` 是离线转换的 KIVAAV03：在同一 23 锚点、PNG、材质、部件、四权重布局上，每材质追加双面标记，每骨追加源模型空间姿态。原始逆绑定矩阵与源姿态分开保存，允许源导入姿态与 bind pose 不同。运行时无需游戏安装、UnityPy 或外部资源服务。

两套资产分别首次加载并缓存 Mesh、Image、材质变体和 IBMs。新角色使用自身结构锚点与绑定数据接收既有动作增量，不能按燕云骨索引取值。源动作的旋转增量沿新角色锚点递归，骨盆仅传相对 rest 的位移；武器位置取同一适配手腕，避免手和武器分别使用两套绝对位置。

## 资源依据与适配边界

本机配置确认李火旺衣装 `3401149 → ActorTemp1210779 → ActorVisualPart10447 → s20`，心素发型 `100407`，烛泪 `2312007 → weapon_manjianghong`。提取与转换的原件哈希、矩阵和材质来源见[随包资源说明](../../assets/lihuowang/README.md)、[来源清单](../../assets/lihuowang/source-manifest.json)及[转换检查](../../assets/lihuowang/conversion-report.json)。

模型组合包含原衣装、心素、惘心笠、原通用基础脸和刀鞘。专属李火旺捏脸参数尚未恢复，通用脸的肤色 / 眼睛为 Kiva 显示适配；不称完整原作脸部复刻。心素保留 6 条有原矩阵唯一匹配依据的离线重建外部父链接，不能冒称原空骨列表保存了这些绑定。头发 RGB 为数据图，只采用原 alpha 与中性黑材质，发饰使用原主色；未知 packed / SH / 各向异性图不当颜色或 ORM。

红斗笠的原物品为 OrnamentItem **3411276「道诡异仙·惘心笠」**，引用 OrnamentConfig **1102706**，battle/UI 原路径均为 `ch_ornament_hat_wuchen_s_lhwdouli`，属于无尘专属头饰，原包 `8/a/8a90c33afec6e79e`。它不是 s20 衣装内被漏画的 FX，也不是心素发饰。帽子的原主体与纱缘正反面四个 LOD0 蒙皮部件按源数据接入，跟随头骨；沿用已发布本体转换 C，不因帽顶增高重新缩小整个人物。帽顶高度另行记录。

帽根引用原 `HairLimitData`（hide mask=4、bone threshold=0.5、limit offset=0.005、maximum scale=0.95、310 字节 limit 数据）。字段与心素局部 tag 有对应线索，但原变形 / 遮发算法尚未恢复。因此保留原发片，并将帽下局部穿插或原发丝形变未移植的边界写入来源清单，不把 mask4 擅自当作整头发隐藏开关。

烛泪以其原四骨当前姿态离线 LBS 烘焙为 Kiva 刚性近战显示，再作握柄和 +Y 轴适配。刀穗不包含原动态模拟；鞘的身体挂接为有记录的美术适配。原动作、动态布料 / 发丝、原 FX / 专用 BRDF 和游戏运行时握持尚未完整复刻。角色朝向、归一化高度和所有身体部件共用同一转换矩阵，不用缺头衣装高度独立缩放。

## 验证范围

转换检查覆盖当前源 LBS 与转换后 LBS、量化四权重和索引、矩阵有限性、完整联合高度、左右锚点、握柄轴及二进制 EOF。Rust 无窗口回归覆盖实际资产加载与换装、源动作 / 现有动作姿态、附件、实体和资源复用、不改变模拟与原角色。Node 直接执行实际 Web 桥检查请求边界。执行项目 `make check`、WASM Clippy 和临时目录 Trunk 构建。

本轮按用户要求不启动浏览器、不截图、不运行常驻开发服务；代码与数值检查不等同于实际画面或手感验收。
