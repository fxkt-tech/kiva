# act 蹲伏移植

参考 `origin/act` 的 `bd3e344`，追加 C 切换蹲伏、慢速蹲行、疾跑滑铲及保持脚部落点的蹲伏 IK。
保留现有武器和联动，不引入旧分支的蹲伏横扫、升龙或其他剑类战斗规则。
继续不创建 Trellis 任务、不使用浏览器测试、不启动或关闭开发服务。

## 顺序与契约

1. 模拟增加 `ActionIntent::request_crouch_toggle()`，以奇偶数锁存切换；两次独立点按在实际固定步前取消，不重复执行。
2. MotionState 拥有蹲伏 / 滑铲状态，公开 `is_crouched/is_sliding/slide_elapsed/slide_direction()` 只读接口。
3. 输入桥使用新动作位 512，KeyC 可信且非重复按下才切换；Web 和原生保留完整按压顺序，失焦清理不重放。
4. 姿态层移植 act 的 0.33m 骨盆下降和双腿 IK，0.12s 平滑蹲下 / 起身，保持脚部位置、腿长及脚掌方向。
5. 验证实际固定步、真实骨骼姿态、输入清理、WASM 构建；不修改角色根高度或镜头锚点。

## 行为

- C 点按切换蹲伏，松开保持，再按起身；蹲行 1.6m/s，蹲伏时不能疾跑。
- 疾跑中 C 启动 0.55s 滑铲，锁定起始世界方向，速度从 5m/s 线性衰减，经现有扫掠碰撞与边界限制。
- 滑铲结束后保持蹲伏，C 可提前起身结束；滑铲期间不能开始新攻击 / 技能 / 联动，站立或结束后按原规则操作。
- 普通蹲伏允许现有攻击和格挡；按住格挡时 C 进入蹲伏格挡，不因残留疾跑锁存误触滑铲。
- 接受跳跃 / 闪避 / 火炮跃进、被击飞、死亡复活和暂停清理会退出蹲伏；冷却拒绝的闪避不改变姿态。
- 空中、闪避中、跃进中按 C 不会排队到落地后执行；暂停通过 Intent 清理请求，在恢复首个固定步清除蹲伏和滑铲。
- Body 的位置 / 占地、MotionState 的跳跃高度、镜头高度与构图保持原所有权；蹲姿不提供额外无敌或穿越障碍的能力。
