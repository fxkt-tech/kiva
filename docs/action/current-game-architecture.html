先有物理与 gameplay 实体，再建立独立显示根、战斗表现、相机和环境，最后通知浏览器 ready。

01

采样输入与请求 RunFixedMainLoopSystems::BeforeFixedMainLoop

鼠标位移直接更新 ViewYaw，移动转成世界方向；离散命令锁存到实际固定步消费。F2／F3 的页面请求也在这里接入。

02

推进规则与真实物理 FixedUpdate · 60Hz · 每显示帧可 0 / 1 / 多次

HitStop 在步头锁定本步门控。motor 先运行，Avian 统一求解，然后发布当前快照；玩家战斗与普通敌人在 combat 中推进，Boss 随后独立推进。

03

消费状态，绘制同一帧 Update → Bevy 全局变换传播与渲染

先同步显示根，再选骨骼动作、求蒙皮与武器挂点，然后普通特效／专用冲击／音频／HUD／相机。事件按各自游标读取，不在每个固定步清空。

01 / PLAYER · AUTHORITY

一个物理玩家100 HP

当前“哥哥／妹妹”是同一玩家的近战／远程模式标签。没有独立妹妹实体或第二套生命。

ActorView.owner 指向物理实体

Avian Position／Rotation／速度为运动权威；Body 发布脚底快照；独立显示根的 Transform 用快照插值。RigPose 只改显示骨骼。

02 / ENEMY · ONE ACTIVE MODE

靶子 或 愁铃客 Boss

F2 在这两种装配之间替换，当前场景只会有其中一种敌人集合。

靶子：100 万血，1.45 倍体型，不追击、不攻击，仍有真实碰撞、击飞和复活。
Boss：标准体型，650 × 2 阶段，独占 BossState。普通 Enemy 主动 AI 跳过它。

玩家和靶子死亡 3s 后复活；Boss 转阶段 2.2s 无敌，击败 3s 后重开；玩家倒地会重置遭遇。

03 / SCENE & RESOURCES

场地、全局资源和各自的唯一写入者

Level 的同一份三角几何分别生成 Collider 与 Mesh。地表／坡道／竹干／岩石参与真实物理；草叶是无碰撞装饰。当前 Level.props 为空。

三种“选择”，分别属于不同模块。

EnemyMode

gameplay 拥有：靶子／实战 Boss，决定装配哪种敌人。


WeaponSet + WeaponMode

simulation 拥有：锤狙／斧炮，与组内近战／远程；会改变实际玩法。

AppearanceSelection

client 拥有：愁铃客／李火旺及对应长刀外观，不改变 WeaponSet、生命或冷却。资产按首次使用加载并复用。

拆招：短窗口免伤与打断

代码沿用 parry 命名，部分旧 HUD 写“卸势”；本图按用户术语称“拆招”。
