# 动作系统重构

## 基础

### 角色
哥哥：主要控制角色，使用近战武器
妹妹：主角的附属角色，不可左键攻击，不可操控，只能释放远程技能

### 属性
生命：归零死亡，先写死1000
耐力：成功防御会消耗耐力，没有耐力后将不能防御，只有在未攻击也未收到攻击时才会慢慢恢复耐力
烈阳：左键攻击命中、技能命中、弹反对敌人造成伤害会积累，每次积累1点，满值10，满了之后可以强化E技能伤害
月光：成功闪避、拆招敌人的攻击会积累，每次积累1点，满值10，满了之后可以强化Q技能伤害
暴怒：释放强化的E和Q技能可以积累怒气，每次释放技能可以积累，近战1点远程2点，满值20，满了之后可以释放暴怒技，暴怒期间基础攻击力翻倍，释放EQ技能都是强化过的，释放前置技能后自动释放联动技，持续20秒。

### 武器特性
武器：角色可以装备多组武器（每组武器一把近战一把远程且绑定，不可自由组合近战远程），每组武器有耐久度，耐久度为50，攻击消耗1，技能消耗10，耐久用完之后自动切换下一组武器。如此循环。
近战：可以攻击、防御、放技能
远程：不可以攻击、只能放技能


### 基础操作
点按鼠标左键：近战攻击，鼠标左右键都是近战武器的动作
点按鼠标右键：拆招。和敌人的攻击对上之后可以免受伤害
长按鼠标右键：防御。防御期间受到伤害的可以减少50%
长按鼠标右键后松开：弹反。和敌人的攻击对上之后可以免受伤害，然后对敌人造成少量伤害并僵直
点按鼠标中键：锁定/解锁敌人
点按Z：切换武器组
点按E：近战技能
点按Q：远程技能
点按Tab：联动技，每套武器都有专属的联动技，按照要求满足前置条件再按Tab即可释放
点按X：释放暴怒技
点按C：蹲伏
点按空格：跳跃，最大支持二段跳

## 武器&技能

### 锤子+鸟铳
- 近战技：选中一个单位，然后使用锤子猛击地面，将周围的敌人击飞
- 远程技：选中一个单位，召唤妹妹拿出鸟铳来一枪，造成伤害和僵直
- 联动技：前置条件：近战技将敌人击飞的时间内。妹妹拿出鸟铳，视角转换到人物位置的仰视角看向敌人，快速来三枪，然后镜头恢复

### 链斧+弓箭
- 近战技：猛然挥击周围，对周围圆形区域造成伤害并减速
- 远程技：选中一个单位，召唤妹妹拿出弓箭将链斧射出去，造成伤害和僵直，之后哥哥会把链斧会拽回来
- 联动技：前置条件：远程技将敌人僵直的时间内。视角转换到人物位置的平视角看向敌人，哥哥拽住链斧将自身拉近敌人，近身的这段时间快速来三发弓箭，然后镜头恢复
