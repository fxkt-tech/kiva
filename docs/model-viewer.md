# 模型、武器与动作验收页

打开开发服务的 `/?view=model`，例如 <http://localhost:3221/?view=model>。部署到子路径时保留路径，例如 `/kiva/?view=model`。游戏进入卡片也有入口，页面右上角可返回游戏。

此页用于人工判断角色模型、武器位置和动作是否正确。它使用游戏实际资产、动画计算、蒙皮和武器挂接；“模型已就绪”只表示画面准备完成，不表示通过美术验收。

## 使用

1. 先选左侧实际配置：哥哥的伏浪锚／谪星摧山、妹妹的引冰落／羿之影，或愁铃客原长刀。也可单独换角色和武器；额外搭配会标为诊断配置。
2. 选择游戏单体动作，暂停后拖动时间轴或前后步进。切角色、武器保留检查时间与观察方向，切动作从头开始。
3. 在画布上左拖环绕、右拖平移、滚轮缩放；使用正面、背面、侧面、俯视和全身取景检查遮挡与穿插。相机在动作暂停时仍可操作，无需捕获鼠标。
4. 右侧可显示骨骼、手腕／握点／枪口、模型根轴和包围盒，并按实例隐藏部件。手腕关节与既有武器适配挂点分别显示；不要把两者的差别直接认作蒙皮错误。
5. 复制检查信息，记录角色、武器、动作、时间、镜头和实际采样信息，方便复现问题。复制需要浏览器允许剪贴板访问。

辅助标记中，紫色十字是手腕，青色十字是武器挂点／发射源，黄色十字是武器握点；坐标轴X红、Y绿、Z蓝。近战挂点包含游戏既有的+0.055m偏移，远程青点对应枪口／箭源。

## 三种检查方式

| 方式 | 用途与边界 |
|---|---|
| 游戏表现检查 | 默认入口。检查游戏使用的裁剪、混合、过渡、持握和 IK；动作由同一显示计算在明确的单体输入场景下推进 |
| 源片段对照 | 查看19个CC0片段与35个已提取源片段，区分素材和适配问题；保留现有根运动剥除／重定向，隐藏手持，不叠加游戏持握修正 |
| 角色参考姿态 | 查看当前资产的导入参考关系；AV03参考姿态不一定等于蒙皮绑定姿态 |

游戏检查以60Hz预览帧重放，倍速只改变播放速度；它不是任意真实游玩的帧录制。行走和跑步在原地检查，妹妹远程检查仅包含单角色持握／瞄准，不演练射击命中或联动。

## 检查范围

模型来自当前运行资源：李火旺、白灵淼、愁铃客，四件指定武器和愁铃客原长刀。源片段数量不等于完整技能数量。
当前材质、脸型、布料与发丝、谪星摧山固定组装等资源适配限制仍保留；页面不会另加偏移掩盖游戏中的错误，也不会修改或上传模型。

完整战斗、伤害、物理位移、飞斧、多人联动和模型编辑不在本页范围。中性灯光便于观察；复用游戏PBR与蒙皮不代表与竹林画面像素同色。
查看页和游戏使用同一WASM，仍需等待程序下载；专用入口避免装配游戏关卡，并未单独缩小下载包。
