# 《百鸟卷》游戏设计与剧情整理

> 本文汇总当前讨论内容。核心玩法、章节结构和双收藏分类已明确；世界观、主线剧情、章节名称、鸟种安排与表现方式为当前草案。
> 各卷的实际关卡数、总卷数及最终鸟类名单尚未确定。

## 一、游戏概述

| 项目 | 内容 |
| --- | --- |
| 游戏名称 | 《百鸟卷》 |
| 主角 | 朱雀 |
| 核心玩法 | 类似 Portal 的传送门空间解谜 |
| 单关目标 | 利用传送门抵达本关代表性鸟所在的位置 |
| 章节单位 | “卷”，按“第一卷”“第二卷”等顺序命名 |
| 章节构成 | 每卷包含 n 个关卡，每关对应一只代表性的鸟 |
| 单关奖励 | 解锁对应鸟的收藏记录与信息 |
| 整卷奖励 | 本卷所有关卡通关后，点亮并收藏完整画卷 |
| 局外入口 | “收集”，下设“画卷”和“百鸟”两个分类 |

剧情主题草案：**朱雀为百鸟找回归途，也在旅途中发现自己的来处。**

## 二、核心玩法与收集规则

### 2.1 单关流程

1. 玩家进入某一卷中的关卡。
2. 观察空间结构与目标鸟的位置。
3. 利用传送门完成空间解谜。
4. 抵达目标鸟所在的位置，完成关卡。
5. 解锁该鸟在“百鸟”中的信息。
6. 更新所属画卷的通关进度。

具体的传送门放置方式、可用表面、移动能力及物理规则，后续另行细化。

### 2.2 整卷流程

1. 每卷包含若干关卡，每关对应一只代表性的鸟。
2. 各关完成后，分别获得对应鸟的收藏记录。
3. 当本卷全部关卡通关时，触发画卷点亮。
4. 完整画卷加入“收集”的“画卷”分类。
5. 玩家可以在局外回看画作和鸟类信息。

### 2.3 进度示例

假设某卷共有 5 个关卡：

| 进度 | 百鸟收藏 | 画卷收藏 |
| --- | --- | --- |
| 0/5 | 尚未解锁本卷的鸟 | 未获得 |
| 3/5 | 已解锁已通关三关对应的鸟 | 未获得，显示进度 |
| 5/5 | 已解锁本卷全部五只鸟 | 点亮并获得完整画卷 |

鸟类收藏与画卷收藏分别解锁。重玩已经完成的关卡时，已有收藏继续保留。

## 三、画卷与关卡的关系

### 3.1 每卷是一幅可以走进去的画

建议每卷拥有统一的环境主题、一幅完整画作和一段章节故事。

完整画作中的不同地点，分别展开为该卷的关卡。例如，一幅溪边村庄的画，可以包含屋檐、庭院、石桥、浅滩和古树，对应五个可游玩的空间。

玩家在关卡中探索这些地点；完成整卷后，通过完整画作看见它们之间的关系。

### 3.2 鸟、栖地与画作一一呼应

每关的代表鸟，与完整画作中的一处栖地对应。

画卷点亮后，玩家能在画中找到此前遇见的鸟，也能认出自己走过的屋顶、桥梁和树林。

核心体验是：**完整画卷承载玩家走过这一卷的记忆。**

## 四、世界观草案

### 4.1 百鸟卷的来历

很久以前，世间降下一场漫长的大寒。河流封冻，森林凋零，迁徙的鸟群始终找不到温暖的地方。

一只通晓绘卷之术的白鹤，向百鸟借来羽毛，并请它们讲述各自记忆中的故乡。

白鹤以羽为笔，将这些记忆画成能够容纳生命的山河。这幅供百鸟栖身的长卷，被称为《百鸟卷》。

白鹤在卷首建起藏鸟阁，供往来的鸟儿歇脚，并封闭画卷通往外界的入口，阻挡严寒。

### 4.2 白蚀与破损的画境

画卷封闭太久，无法得到外界新的风、阳光与雨水，画中的颜色开始褪去。这种现象被称为“白蚀”。

道路、桥梁和河道逐渐失去联系，各片山水散落在互不相通的画层中。

鸟儿被困在各自最后完整的栖处。即使看得见远处的景物，也无法通过普通移动或飞行跨越断开的画层。

### 4.3 朱雀与传送门

朱雀的火焰能够连接画境中断开的空间。这是传送门玩法在故事中的解释，具体操作规则仍由关卡设计确定。

每只鸟记得故乡的一部分。朱雀抵达它们身边，便接通对应的栖地，让这只鸟的形象、名字与故事重新显现在卷中。

当一卷的所有鸟都被找到，散开的栖地重新相连，完整画境恢复色彩，触发画卷点亮。

> 每只鸟，都记得故乡的一部分。百鸟的记忆重新汇聚，一方山河才能恢复完整。

## 五、主要角色草案

### 5.1 朱雀

- 玩家操控的主角。
- 刚从藏鸟阁中央的古灯中孵化，对世界充满好奇。
- 能够用火焰连接空间，为百鸟打开归路。
- 最初的愿望是接回百鸟，然后去看看真正的天空。
- 中途发现自己曾被百鸟共同保护，从此主动承担起把大家带回家的愿望。

### 5.2 白鹤

- 百鸟卷的绘制者与守卷者。
- 前期通过画影和声音引导朱雀。
- 熟悉百鸟的习惯，始终替它们安排归处。
- 真身被困在卷尾，长期支撑着破损画卷的通路。
- 是主线最终需要接回的鸟。

### 5.3 百鸟

- 每关对应一只具有代表性的鸟。
- 每只鸟都有自己的栖地、性格和一段简短故事。
- 它们的记忆共同构成各卷山河。
- 它们曾在严寒中共同保护朱雀卵，与主角有尚未揭开的联系。

## 六、主线剧情草案

### 6.1 序章：空阁初醒

朱雀在藏鸟阁中央的灯盏中孵化。

阁中空巢落灰，池水干涸，留下谷子、细草与羽毛等旧物。玩家暂时不知道这些东西的来历。

白鹤的画影告诉朱雀：百鸟被困在破损的画卷中，只要接回它们，就有机会修复画卷，重新打开通往外界的门。

朱雀问外面有什么，白鹤回答：

> “真正的风。还有，画不出来的太阳。”

朱雀由此踏上寻鸟之旅。

### 6.2 前期：逐卷寻鸟

朱雀进入各卷，利用传送门抵达被困的鸟，逐渐恢复画境。

部分鸟表现出对朱雀的熟悉：有的说它长大了，有的下意识替它挡风，有的把谷子或柔软羽毛放到灯盏旁。

这些细节埋下疑问：刚刚诞生的朱雀，为什么会被百鸟认得？

### 6.3 中期：百鸟曾经保护过你

随着画卷恢复，朱雀看见一段往事：

当年大寒降临，白鹤在雪中发现了一枚几乎失去温度的朱雀卵。

百鸟为它停下迁徙的脚步，轮流挡风、保温，衔来干草与食物，最终将它一起带入百鸟卷，安置在藏鸟阁的灯盏中。

阁中保存的旧物，正是当时留下的东西。

一只普通的小鸟说：

> “我们那时候，也不知道你以后会是什么样。”
> “只是觉得，这么小的一颗蛋，不能留在雪里。”

朱雀明白：自己正在寻找的百鸟，曾共同保护过尚未出生的自己。

### 6.4 后期：始终没有归来的白鹤

越来越多的鸟被找到，但白鹤始终只以画影出现。

朱雀最终得知，白鹤当年留在卷尾固定卷口，此后一直支撑着残存的通路，真正的身体也被困在那里。

此前每恢复一处栖地，朱雀留下的火印和归来百鸟的鸣声，都会分担一部分维持画卷的力量。

随着画境逐步修复，百鸟终于能够共同支撑完整画卷，朱雀也有机会把白鹤接回来。

### 6.5 最终关：这一次，你带路

最后一关继续沿用“抵达目标鸟所在位置”的通关方式，目标鸟是白鹤。

关卡由此前各卷中熟悉的空间片段组成。朱雀运用一路学会的空间解谜方法，接通通往白鹤的道路。

每接通一段路，便传来已经找到的鸟的回应。

朱雀最终抵达白鹤身边：

> 朱雀：“大家都到了，就等你了。”
>
> 白鹤：“好。这一次，你带路。”

接回白鹤后，完成最后一卷，并触发最终的画卷点亮。

### 6.6 结局：窗外有春天

完整的百鸟卷重新连通，藏鸟阁通往外界的门再次打开。

一片真正的树叶随风落入，朱雀发现外面的冰雪已经消融，春天早已归来，只是封闭的画卷一直没有收到这个消息。

百鸟重新获得通向故乡的道路。藏鸟阁成为可以自由往返的归处，白鹤终于能够安心休息。

结局后，已解锁的画卷与百鸟信息继续保留，供玩家回看。

## 八、画卷点亮的表现建议

未完成的画卷可以使用暗淡轮廓或淡墨稿呈现，并显示当前通关进度。整卷通关时，再一次性显现完整色彩。

建议演出顺序：

1. 朱雀抵达本卷最后一只尚未找到的鸟。
2. 鸟鸣响起，脚下的羽纹亮起。
3. 本卷此前找到的鸟依次回应。
4. 镜头拉远，分离的关卡空间逐渐收回完整画作。
5. 色彩沿溪流、枝条或画中道路铺开，山水恢复生机。
6. 显示卷序、画卷题名与“画卷已收集”提示。
7. 用一段简短旁白或画面，推进章节剧情。

《春溪初醒》的卷末旁白示例：

> “溪水重新认得归路，屋檐重新等到了春天。”

全部主线完成后，可让已收集的画卷依次展开，连成完整的《百鸟卷》，作为片尾表现。

## 九、局外“收集”系统

局外入口名称为“收集”，包含“画卷”和“百鸟”两个分类。

“藏鸟阁”可以保留为这个收藏空间在世界观中的称谓，具体是否使用该名称仍可调整。

### 9.1 画卷

核心功能：查看已经收集的完整画作。

建议内容：

| 内容 | 说明 |
| --- | --- |
| 卷序与题名 | 例如“第一卷·春溪初醒” |
| 完整画作 | 展示本卷恢复后的山河与百鸟 |
| 卷序短文 | 用简短文字介绍这一卷的地方与故事 |
| 本卷百鸟 | 列出本卷对应的鸟类条目 |

可选交互：

- 放大、拖动查看画作细节。
- 点击画中的鸟，跳转至对应的“百鸟”条目。

### 9.2 百鸟

核心功能：查看已经解锁的每只鸟的信息。

建议内容：

| 内容 | 说明 |
| --- | --- |
| 名称与形象 | 展示鸟的名称及清晰形象 |
| 所属画卷与关卡 | 标明玩家在哪里遇见过它 |
| 基础介绍 | 介绍鸟本身的特点 |
| 卷中故事 | 记录它在游戏中的经历、性格或心愿 |

基础介绍与卷中故事分别呈现。现实鸟类的信息与游戏原创设定应清楚区分；神话鸟类可采用对应的世界观介绍。

翠鸟的“卷中故事”示例：

> 溪水褪色以后，它仍守在那根伸向水面的树枝上。
> 它说，总要有谁记得，这里从前是一条河。

白鹤的结局收藏文案示例：

> 曾经守着一整卷山河。
> 如今最喜欢在有风的窗边打盹。

## 十、叙事与体验原则

1. **单关有明确目标。** 玩家通过空间解谜抵达代表鸟的位置，并获得对应的鸟类收藏。
2. **整卷有完整回报。** 本卷全部关卡通关后，点亮并获得一幅完整画作。
3. **关卡与画作相互对应。** 玩家能在完整画卷中认出走过的地点和遇见的鸟。
4. **普通关卡采用轻叙事。** 用入关一句话、抵达时一个动作、收藏中一段短文塑造鸟的个性。
5. **主要剧情在卷末推进。** 正常通关即可理解主线，收藏资料补充细节。
6. **结局延续核心玩法。** 最终救援通过传送门解谜和抵达目标完成。
7. **收藏成果持续保留。** 通关后仍可欣赏画卷、查看百鸟信息。
8. **当前功能范围保持清楚。** 双收藏系统以画作展示与鸟类信息为核心；画卷交互等扩展作为可选方案。
