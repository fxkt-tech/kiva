- [x] 动作系统。支持疾跑、跳跃、闪避、格挡、蹲伏、滑铲
- [x] 武器系统。角色身上两个人格，一个哥哥人格一个妹妹人格，哥哥使用近战武器，妹妹使用远程武器，每一套武器都有一个近战一个远程，并且两把武器的技能之间有联动。滚轮可以切换近战和远程武器，当释放某个联动技能时，点按Tab可以释放联动技
  - [x] 锤子、狙击枪：锤子选中一个敌人然后击飞附近的所有敌人，在这段时间使用联动技可以衔接远程可以对选择的敌人狙击一枪
  - [x] 斧子、火炮：火炮起手，向选中位置跳跃，跳跃过程中使用联动技可以使用斧子旋转
