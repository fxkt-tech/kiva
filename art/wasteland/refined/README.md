# concept-v11 造型与模型细化

主文件为 `zhuque-v11-refined.blend`，保留完整可编辑曲面与兼容骨架。原 [灰模](../greybox/zhuque-v11-greybox.blend) 不覆盖。这里的全身图、细节图和动作图都是真实 Blender 网格渲染，不是概念图投影或图像生成替代模型。

## 本阶段变化

- 发型重做为有厚度的弯曲扁束：中分主束、侧层、后颈扇束与少量交叠横扫束，保留少量暗火色发尾占位。
- 外衣有腰际下摆、局部张力褶、软化肩部及每侧两层长短短袖；内长袖仍为纯色。裤装保持连通腰裆与阔腿，加入沿重力的垂褶、膝部压褶和宽裤脚落布，不增加腰带。
- 围巾由宽布包裹与不规则折边构成，不再沿用三个均匀圆环；披风保持认可的不对称轮廓，尾羽线条更弯曲。
- 朱雀纹样改为具有鸟头/冠/喙、S 形颈身、双翼和尾羽的浅浮雕部件，贴合外衣表面，后续再处理织物/材质融合。
- 越野鞋重做分区厚底、低帮鞋面、弧形鞋头保护、鞋舌、交叉鞋带、后跟护片/提环和角状抓地块。
- 静态少年脸部比例、眉眼和嘴角使用独立细化 helper；头部基础仍明确来自官方 Blender CC0 拓扑，未增加面部表情系统。

来源和已有坐标转换见 [灰模来源](../greybox/provenance.md) 与 `head-study.report.json`。新增衣装/发/鞋/纹样曲面为脚本创作，不读取旧游戏角色网格或纹理。四种预览材质帮助区分层次；其中细微程序织物 bump 明确为预览，当前不宣称已完成最终 UV、PBR、皮肤/布料绘制或动态火焰。

## 验证与图像含义

`refined-report.json` 记录基础及求值后三角面、权重/自身绑定误差与全部 140 个真实目标快照的骨矩阵/LBS 有限性。仍以 40,000 求值后三角面为上限，身体 52 个关节、参考根和三根独立披风辅助骨保持兼容边界。

`front/back/side/three-quarter` 为中性绑定姿势；`head-and-sleeve-detail` 与 `shoe-structure-detail` 是形体细节。`authored-relaxed-review` 是额外制作的放松手臂审阅姿势，`stress-*` 是局部压力示意。`runtime-*` 才是共享 Kiva 驱动快照，原名和时间在 `runtime-render-index.json`，不能混称。

披风辅助骨目前继承躯干，不包含布料模拟或完整动态约束；宽裤、肩袖和披风在极限战斗姿势的穿模仍需要后续针对性处理。模型细化不等于完整游戏接入，最终纹理、真实刀刃轨迹对比和运行验收仍是后续工作。

复现命令与模式说明见 [制作工具](../../../tools/wasteland/README.md)。
