用户已于2026-11-15确认concept-v11作为建模原型，进入原创三维灰模与兼容骨架绑定。旧Logo文件只作历史追溯，后续设计不再使用。灰模产物放greybox/，最终模型与游戏接入尚未完成。
## 概念版本
- v01：成熟废土军装方向，用户修订为少年。
- v02：灰紫现代武侠少年，过于干净且披风不符，被否定。
- v03：过度破损/碎布/补丁，用户指出不是乞丐，被否定。
- v04：完整合身的适度旧衣，少年形象；披风随后被指定改为马克式黑灰披布。
- v05：黑灰绕颈覆肩披风方向；用户要求重配上衣与阔腿裤、调整面貌和中分发型。
- v06：阔腿裤、实用背心/卷袖旧衫、中分黑发和更坚定面貌。用户随后要求整体朱雀意象。
- v07：“灰烬与余火”试案；用户随后指定紧身护甲/Logo/宽披风烧灼渐变，并要求更强朱雀形态融合。
- v08：用户指出紫色重、龙骑士护甲感、Logo未融入，要求重做。
- v09：披风被用户明确认可并要求保留；衣裤/脸要求重做。
- v10：层叠旧衣与少年脸；用户进一步指定短上衣/双层短袖/纯色内袖/取消Logo及少量焰尾发梢。
- v11：用户已确认为建模原型；腰际短上衣、两层长短外短袖/纯色紧身内长袖、原创朱雀纹样与少量焰尾发梢。
