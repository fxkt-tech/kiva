## 造型来源

沿用项目随包的白灵淼女性基脸、身体、莲母发型与衣装拓扑。23 个结构驱动、既有部件各自的关节顺序、sourceRestModel、逆绑定和量化权重来自同一女性底模。输入 `assets/characters/bailingmiao.bin` 的 SHA-256 为 `adaeb80895ade1234677fd3b024dba459621b395e8d478ff222b74f28402408b`。底模导入及来源清单见[白灵淼](../bailingmiao/README.md)。

本次按绘卷中的青羽与金玉设计了三层披肩羽、两束长背羽、单侧上挑冠羽、扣座和玉坠。羽片是具有弯度、羽脊和尖端轮廓的三维网格，两肩与手臂混权，背羽在胸椎、骨盆与对应大腿间过渡，发簪和玉坠跟随头骨。关节参考取自底模的结构锚点，新衣饰使用自己在模型空间建立的绑定。绘卷见[废站参考图](../../../art/station/v1/station-target.png)。

## 复现

导出环境为 CPython 3.13.11、NumPy 2.5.4、Pillow 13.0.0。在仓库根目录重建或逐字节校验成品。

```sh
uv run --offline --python 3.13 --with numpy==2.5.4 --with pillow==13.0.0 python tools/station/build_qingluan.py
uv run --offline --python 3.13 --with numpy==2.5.4 --with pillow==13.0.0 python tools/station/build_qingluan.py --verify
```

废站待机先注视弟弟，激活约 2.6 秒后头颈开始转向车窗。胸肩、双臂、两腿接续动作，约 5.9 秒完成转身。技能与联动使用原模拟给出的站位、射击源和真实武器装配，结束后同一显示根回到水边。可在模型验收页选择「青鸾 · 废站」与「无手持」，从正面、侧面、背面检查服装。关卡水面和模型查看页使用同一 AV03 资源。[模型验收页四向取景](../../../art/station/qingluan-turnaround.webp)
