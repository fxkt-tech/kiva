# 恢复骨骼角色与动作表现

## 目标
将当前胶囊角色替换为 act 分支的分段火柴人骨骼样式，让当前游戏操作具有清楚、连贯的动作反馈。

## 已确认事实
- 用户指定 act 分支样式（bd3e3443cfb2922c5cbf6a682cb75bb1091fea12）；该分支以23骨骼、刚性分段、关节球、头部、右手剑表现角色。
- act 的 stickman.anim 内嵌19段CC0动作，根平移已去除；无需加载新网络资源。
- 当前世界位置、前摇、后摇、技能提交、控制、死亡重生均由 simulation 负责；角色表现读取该状态。

## 范围与要求
- R1 玩家与NPC采用旧分支同类骨骼火柴人，保留友敌颜色、头与眼睛、持剑外观。
- R2 提供待机、实际移动、普攻前摇与后摇、施法/引导/恢复、冲刺及受控的骨骼动作；按当前动作和执行类型选择，不判断具体角色或技能ID。
- R3 暂停冻结已显示骨骼；死亡沿用隐藏，重生清除上次生命的动作状态，重新选角清理完整模型后重新生成。
- R4 动作不修改权威位置、不改变技能或普攻时机；血条、拾取、底座继续跟随显示根。
- R5 导入来源及许可完整保留，代码按资源采样、骨架/附着、动作适配划分，避免恢复旧战斗系统。

## 验收
- [x] 玩家与NPC可见多关节火柴人及随手移动的剑，不再是胶囊占位模型。
- [x] 待机有呼吸、移动有步态；攻击前后摇骨骼姿势不同，取消/技能切换可以恢复，技能与控制动作可观察。
- [x] 原生/WASM使用相同内嵌数据，所有采样有限、四元数归一、根平移为零；剑与手附着连续。
- [x] 暂停骨骼保持不变，重生/整场重开没有旧姿态、孤立部件或重复模型。
- [x] make check与WASM Clippy通过；有窗口浏览器smoke、技能/击飞拾取、血条、选角重开相关回归通过，截图确认外观。

## 不在范围
恢复act旧动作游戏的战斗/连招/输入/相机；更改现有角色、技能、普攻规则；制作新美术；引入蒙皮模型或通用动画编辑器；未授权的自动提交推送或接管用户服务。
