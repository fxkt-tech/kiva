# 统一模型命中与敌方剑形光标

## 目标与最新要求
用户要求鼠标放到敌人模型上即可命中，并显示剑形鼠标；明确只检测模型，血条不参与。本任务保留阵营无关的公共几何入口，便于未来友方技能复用，不在本轮新增友方技能。

## 背景
原controls::hovered_unit只按固定身体AABB取最近单位，动作肢体/武器可能伸出边界；右键再过滤敌人，友军重叠会挡住后面的合法敌人。攻击射程本来不限制选中。此前提出的标签命中方案已被用户排除，不实施。

## 要求
- 命中实际已显示的敌方模型，包括动作肢体/武器；提供小量固定CSS像素边缘容错（6px），不改模拟碰撞半径，不用未插值UnitPose替代显示变换。
- 血条、名字与其它标签都不作为可选区域，不加DOM命中桥或标签点击逻辑。
- 模型几何检测返回有序公共候选，不硬编码敌友/射程/具体技能；当前控制器从候选中选择合法敌人供右键/Enemy技能复用，未来友方技能接入自己的资格规则即可。
- 悬停高亮并切剑形，离开敌方模型恢复箭头；悬停不自动提交攻击或更换持久selected，点击才执行。敌方目标每显示帧发布，不能等80ms完整快照。
- 用户追加：A+左键点击敌方模型必须锁定同一命中目标并更新selected，不能提交空地AttackMove后改选其它近敌；只有点空地才保留攻击移动自动索敌，不能黏住旧selected。
- HUD/小地图、UI拖动、暂停/失焦/失锁/死亡/不可见和重选时不得残留剑形或误发命令。保留按下快照及超距追近语义。

## 验收
- [x] 敌方身体、动作肢体/武器都能命中并显示剑形；模型外有限容错以外恢复箭头，地面仍可点击。
- [x] 血条/名字空白边缘不触发模型命中或剑形；HUD/小地图保持箭头及输入隔离。
- [x] 友敌重叠时右键从相同候选中找到合法敌人；当前敌方技能与右键共用几何，公共候选可由友方资格谓词复用。
- [x] A+左键点模型发明确AttackTarget并选中该敌人，即使另一敌人更近；点空地仍AttackMove、不锁旧selected，友方/隐藏单位不能变显式攻击目标。
- [x] 远近镜头、800×600与DPR2按CSS像素保持判定，超距普攻仍追近；攻击伤害仍由模拟结算。
- [x] 隐藏、死亡、旧实体、暂停/失锁/失焦和重选不误命中；击飞按实际模型，不选旧地面位置。
- [x] 原生专项、完整质量门及真实模型/光标浏览器回归通过，规范/架构同步。
