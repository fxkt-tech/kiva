## 评审重点

1. 七项属性真正驱动行为，所有调用方都读取最终值，静态字段没有混入修正。
2. 来源修正能替换和移除，无逆向减法恢复、重复装备残留或死亡残留。
3. 攻方提交快照与守方命中抗性时机一致，已提交效果不依赖来源实体存活。
4. 普攻时序只有一个事实来源，走砍与修改攻速均不能刷新已提交间隔。
5. HUD 放置、窄窗口和 UI 输入隔离符合要求，已有鼠标/血条修复不回退。
6. 本期没有顺带实现装备、完整状态效果或角色选择，也没有为其搭建通用插件框架。
