## 必测场景矩阵

| 场景 | 断言 |
|---|---|
| 单位/方向/地点/自身投递 | 注册合法组合、拒绝非法组合；同载荷复用 |
| 同tick双方施法 | 已提交效果均保留，不因查询顺序提前控制另一方 |
| 有序效果 | 致死后跳过状态；状态后致死清理；0伤害后控制生效 |
| 一步控制/100ms | 限制恰好N个后续动作步，无零作用或多一步 |
| 中断 | 前摇无消耗、引导停止未来脉冲、后摇取消不刷新间隔 |
| 禁锢 | 能普攻/普通施法，不能走路/自主Dash；攻击移动只执行允许部分 |
| 状态叠加 | 同源刷新/异源独立，Root/Stun/Force分别结束不提前解锁 |
| 减速数学 | 1.2×0.7=0.84，最强接替，0倍可恢复，Default=1，饱和发生在最终乘算后 |
| 强制运动 | 碰墙、边界、零行程、覆盖、Stop、途中死亡；不叠加步行 |
| 生命身份 | 旧锁定目标不能命中复活新生命；地面区域可以命中当前生命 |
| 显示 | 击飞位置能点、血条逐帧跟随、暂停冻结、DPR2/缩放、模型后摇保持 |
| UI | 装配驱动名称与瞄准，点击隔离、控件反馈正确，144px无单位属性区不回退 |
