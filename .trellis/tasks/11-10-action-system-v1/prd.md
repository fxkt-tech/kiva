# 动作系统重构第一版

状态：用户在审阅详细方案、确认临时模型并查看当前机制图谱后，明确回复“开始实现吧”；按本方案实施第一版。
阅读顺序：本文 → [技术设计](design.md) → [实施计划](implement.md)。
现状证据见 [现状调查](research/current-system.md)。

## 目标与价值

让玩家始终操控哥哥，通过近战、妹妹远程技能和有前置条件的联动形成完整战斗循环；在现有竹林、靶子和愁铃客实战中可以操作、观察并验证。
第一版先验证角色分工、右键手感和两套武器的区别，为之后的能量玩法提供稳定底座。

## 背景与依据

- 需求来源：[动作系统重构](../../../docs/action/动作系统重构.md)及当前会话。原文描述完整愿景；本任务按用户确认的第一版取子集。
- 现有游戏通过切换近战／远程模式表达哥哥／妹妹，采用锤狙和斧炮联动；本次会替换这些规则。
- 保留 client → gameplay → simulation 单向依赖，以及 Avian 唯一运动权威、60Hz 固定步与只读表现。
- 当前事实、源码位置及需要迁移的调用方集中记录在 research/current-system.md，未实现的方案不写入现行规范。

## 已确认需求

| ID | 要求 |
|---|---|
| R01 | 哥哥始终为主要控制角色；妹妹不可直接控制、不接受左键普攻，通过远程技能和联动独立出场；第一版不增加妹妹的寻路、独立生命或受击规则 |
| R02 | 绑定武器组为锤子＋鸟铳、链斧＋弓箭；第一版保留手动切换，不再通过近远程模式替换哥哥 |
| R03 | 左键近战普攻，E 普通近战技，Q 普通远程技，Tab 在有效前置条件内释放对应联动；E／Q 按下立即响应，长按不重复施放 |
| R04 | 中键锁定／解锁；保留 WASD、Shift 闪避／疾跑、C 蹲伏及现有滑铲、空格二段跳；跳跃按下立即响应 |
| R05 | 卸势统一称“拆招”；右键按下开启拆招窗口，持续按住进入防御，从防御状态松开开启弹反窗口；短按松开不额外弹反 |
| R06 | 有效防御减伤 50%，成功防御消耗耐力，耐力不足不能防御；只有未攻击且未受到攻击时逐渐恢复耐力；无防御次数限制和破防惩罚 |
| R07 | 玩家生命上限 1000；继续使用现有死亡、3 秒后复活与靶子／实战模式 |
| R08 | 锤子 E 以选中目标周围为范围击飞；鸟铳 Q 由妹妹向选中目标开一枪，伤害并僵直；在该次 E 造成的浮空期间，Tab 召唤妹妹向原目标快速开三枪，使用低位仰视镜头后恢复 |
| R09 | 链斧 E 伤害并减速周围敌人；弓箭 Q 由妹妹将链斧射向选中目标，伤害并僵直后由哥哥收回；该次 Q 僵直期间 Tab 让哥哥拉近原目标，妹妹在拉近过程中快速射三箭，使用平视镜头后恢复 |
| R10 | 按锤鸟完整闭环 → 防御与耐力 → 链斧弓推进；每个检查点都可以验证，最终两套玩法共同验收 |
| R11 | 用户确认第一版可使用有辨识度的临时妹妹模型和程序化武器，正式美术后续接入；临时资源仍需清晰表现独立出场与四种武器 |
| R12 | 开始重构前，先交付一份当前游戏机制与代码结构的独立 HTML 图谱，覆盖现有模块、运行时序、实体状态和主要玩法调用链 |

## 本次实施采用的行为基线

以下基线随用户本次“开始实现吧”的明确授权采用；数值详见 design.md，作为首轮可调参数，调整不得改变已确认范围。

| ID | 建议行为 |
|---|---|
| P01 | 1／2 手动选组；滚轮不再切换哥哥／妹妹。默认不自动锁定，中键在可见候选中按面朝方向选取；解锁后保持无锁定 |
| P02 | 未锁定也可朝面前普攻、使用链斧 E；锤子 E 与两种 Q 需要显式锁定，不暗中替玩家选目标。无效请求提示原因，不启动冷却 |
| P03 | E／Q 各自拥有冷却，切组不刷新；两套共用 E 槽冷却和 Q 槽冷却。第一版不做攻击输入缓冲或复杂取消连段 |
| P04 | 拆招仅免伤，弹反免伤并使攻击者僵直；二者第一版不附加反伤。耐力只约束持续防御，拆招与弹反不扣耐力 |
| P05 | 正面判定沿用当前面对攻击来源的方向阈值。防御中允许慢速移动，禁止攻击；耐力不足时该次来袭按普通命中处理，不增加硬直惩罚 |
| P06 | 普通技能和联动有明确动作占用；妹妹技能期间哥哥仍是受控角色，不额外获得无敌。联动期间禁止新攻击、切组与其他主动动作；输入即时拒绝，不排队 |
| P07 | 联动只关联造成前置条件的技能、武器组与原目标；中键改变当前锁定不改变已记录的联动目标。Tab 接受后，原目标自然落地／僵直结束不取消已经承诺的三发 |
| P08 | 拉近不能穿墙、瞬移或追逐新目标；目标失效、严重高差、拉动被障碍阻断时停止，跳过后续未发射攻击并恢复镜头 |
| P09 | 当前 F3 外观选择只影响哥哥身体／服饰，保留已有两套外观；战斗手持外观按锤／链斧显示，不再被 F3 替换成长刀 |
| P10 | 保持现有 Boss 的生命、攻击数值、阶段和转阶段无敌；第一版不借角色生命变为 1000 顺带重做 Boss 平衡 |

## 验收标准

每条 AC 按真实可观察行为验收，参数调整不能取消对应行为。

| ID | 对应需求 | 验收结果 |
|---|---|---|
| AC01 | R01–R04、P01 | 哥哥持续可见并承接移动；左键始终为当前组近战；E／Q 不需滚轮切形态；1／2 切组和 HUD 一致 |
| AC02 | R04、P01–P02 | 中键一次锁定、再次解锁；解锁跨多步不会自行选回；无目标时需要目标的技能拒绝并提示，不扣冷却，普攻和链斧 E 仍可用 |
| AC03 | R05–R06、P04–P05 | 短按只开拆招；长按进入 50% 减伤；从有效防御松开产生一次弹反窗口；正背面、耐力不足、冷却中及同帧按下松开均按约定处理 |
| AC04 | R06 | 成功防御扣一次耐力；拆招／弹反不误扣。攻击活动或实际来袭使恢复等待重新开始；安静后恢复，暂停不恢复；连续超过三次有效防御不会因次数破防 |
| AC05 | R07、P10 | 玩家最大生命 1000；死亡不能新起手，复活清理输入、目标、联动和妹妹出场并恢复生命／耐力；靶子和 Boss 的现有身份规则保留 |
| AC06 | R08 | 锤 E 真正造成范围伤害和约 3m 的物理击飞，Q 真正单发伤害和僵直；Tab 仅对这次 E 的原目标触发，分别在三个时间点结算三发 |
| AC07 | R09 | 链 E 范围伤害与减速可测；Q 有链斧离手／命中／回收；只有实际施加僵直才开放 Tab；拉近与三箭真实执行、沿途经过 Avian 碰撞 |
| AC08 | R01、R08–R09、R11 | 妹妹以独立可见形象完成出场／射击／退场，枪口或箭口来自妹妹；哥哥不变成射手，第三发前击倒目标不会造成剩余重复伤害；第一版允许有辨识度的临时模型 |
| AC09 | R08–R09、P07–P08 | 原目标死亡／移除、模式切换、玩家死亡、视线阻挡、墙体和高差具有确定结果；不会跳到新目标、补发旧枪／箭或残留镜头 |
| AC10 | R03–R05 | 原生与 Web 按键语义一致；零／多固定步不丢失或重复指令；右键按下、松开顺序保留；失焦／失锁不制造弹反或恢复后幽灵输入 |
| AC11 | 全部 | E／Q／Tab 可用性、各自冷却、耐力、目标血量与状态由模拟快照显示；没有首版之外的占位能量条或按键提示 |
| AC12 | R04、R07–R09 | 暂停冻结物理、动作、AI、耐力、冷却及镜头时间线；保留原有二段跳、支撑、坡地、碰撞、HitStop 和普通镜头构图 |
| AC13 | 全部 | 完成真实固定步回归、实际桥脚本 Node 测试、原生／WASM 检查，以及单独记录的画面／手感验收；自动检查通过不代替视觉验收 |
| AC14 | R12 | HTML 可直接打开、无需联网；显示当前实现的真实操作与数值，支持模块定位、玩法链路查看、时序和状态归属，不混入第一版拟议机制 |

## 第一版之外

烈阳、月光、强化技、暴怒状态、暴怒技、结束后的虚弱、耐久、耐久自动换组、破防及防御命中次数限制均不实现。
不新增妹妹独立 AI／生命／碰撞、不新增其他武器组、不建立通用技能编辑器、不恢复完整原作技能映射，也不重新设计地图。

该四项追加要求由 [模型接入子任务](../11-10-action-v1-models/prd.md) 实施，替换 R11／AC08 中对应的临时外观；该轮保留了锤子、链斧的临时模型。

原有真实 GPU 画面验收仍独立跟踪，新的资产接入不自动视为该项已经通过。
