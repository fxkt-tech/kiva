# 可切换渲染风格：写实 PBR / 岩彩

## 背景

竹林演武目前只有一种渲染方式：Bevy 延迟 PBR + `ForestMaterial` 林地细节 + SSR 湿地反光 + 级联阴影 + 距离雾。美术方向（见归档任务 `11-18-handscroll-art-direction`）借鉴《阴阳师：百闻牌》的线描与重彩设色，希望 3D 场景也能呈现岩彩效果，同时保留现有写实效果用于对比和回退。

## 目标

1. 建立**可扩展的渲染风格框架**：一种风格 = 表面着色 + 场景光照配置 + 镜头后处理链的组合，后续可以继续添加风格（例如水墨）。
2. 交付两种风格：
   - **写实（PBR）**：即现有效果，切回时必须与现在逐项一致。
   - **岩彩**：矿物色平涂、分档明暗、冷色阴影、墨线描边、纸纹与颜料颗粒，哑光无高光。
3. 运行中可用**快捷键 F8** 在当前关卡支持的风格之间循环切换（F4 保留给碰撞调试）。

## 范围

- 首期：**竹林演武**完整支持两种风格；角色（哥哥、妹妹、敌人）、武器、技能特效在岩彩下也要协调。
- 框架对两个关卡通用；**废站首期只登记写实风格**，F8 在废站不切换并给出提示，岩彩废站另开任务。
- 模型查看器（`?view=model`）保持写实，不接入切换。
- 首期复用现有贴图，通过着色和色板映射得到岩彩效果；**重绘贴图不在本任务范围**。

## 交互要求

- 原生：窗口有焦点且模拟激活时响应 F8，与 F3 规则一致；窗口标题显示当前风格。
- Web：在捕获状态下响应 F8，由 JS 拦截并阻止浏览器默认行为，经 Rust 单次消费，Rust 渲染确认后 HUD 显示「渲染 · 岩彩 · F8 切换」；操作说明表增加一行。
- 风格选择只属于客户端表现，不进入模拟、不影响战斗结果，暂停时也可以切换。
- 切换在一帧内完成，不重建场景实体、不重置角色姿态、不改变镜头。

## 验收标准

- [ ] 竹林中按 F8 在写实 / 岩彩之间切换；多次往返后实体、网格、材质、贴图数量不增长。
- [ ] 切回写实后：灯光、环境光、雾、清屏色、SSR、相机组件、材质参数与当前版本完全一致（World 回归测试逐项断言）。
- [ ] 岩彩下：环境与角色都是分档明暗、冷色阴影、无镜面高光；物体轮廓有墨线；画面有纸纹和颜料颗粒；颜色收敛到矿物色板。
- [ ] 受击变色、敌人蓄力提示、角色特效在岩彩下仍然可见、可区分。
- [ ] F8 在废站为无操作，提示当前关卡只有写实；F2 / F3 / F4 的行为不变。
- [ ] Web（WebGPU）与原生都能运行岩彩；记录两端在岩彩下相对写实的帧耗时变化。
- [ ] 新增的 WESL 着色器通过与现有 `forest_material` 相同的无 GPU 组合测试。
- [ ] 静帧截图（同一机位，写实 / 岩彩各一张）附在任务目录，供美术评审。

## 不做

- 重绘竹林贴图、新建模型。
- 废站岩彩、模型查看器岩彩。
- 风格选择持久化（重启后回到写实）。
