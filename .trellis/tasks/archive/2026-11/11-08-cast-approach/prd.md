# 指向性技能超距走近后施法

## 目标与已确认行为
用户先要求超距走近施法，随后明确只有瞄准敌人的指向性技能需要追踪；非指向性朝指定方向释放，保留插旗和冲刺的最大距离语义。用户进一步说明应按目标方式采用通用逻辑，不按英雄/技能分别实现。

- Targeting::Enemy命令锁定当前敌方单位生命；超距时先寻路走进施法范围，再自动开始一次施法。
- 方向技能不追踪地点/敌人；地点、自身及既有最大射程截断行为保持。
- 追近时不扣法力、不启冷却；到范围才开始既有前摇与原子提交；提交前继续校验来源、目标生命、视野、控制和资源。
- 只保留一条待施法意图，新合法移动/攻击/停止/技能替换它；非法输入不得破坏原有效意图。
- 目标死亡/重生/失去视野、装备来源失效、无可达施法位置时取消，不能追踪旧生命或悄悄重试已中断施法。
- 原生暂停、死亡/重生、整局reset和卸装保持生命周期正确；英雄和装备主动共用规则，无英雄/技能ID分支。
- 用户管理开发服务；仅在用户明确授权后提交/推送。

## 仓库证据
- src/client/controls.rs点击Enemy前用preview_cast拦截全部错误，超距请求未进入模拟。
- actions::begin_cast直接调用严格preview_cast；orders::resolve_target对Enemy超距返回OutOfRange，无追近意图。
- Direction已经表示方向向量，不需要/不应根据点击远近移动；Point Dash/Standard/Scout已在模拟截断最大射程。

## 验收
- [x] 真实Enemy技能超距只需点击一次，先移动，在范围内只提交一次；途中不扣费/CD。
- [x] 移动目标重新规划，绕过障碍到可施法位置；可施法位置可达即可，不要求走到敌人中心。
- [x] 新指令取消/替换，非法指令保留；死亡、旧生命、丢视野、卸装、暂停/重开均无残留。
- [x] 原Direction和Point最大范围行为、AI严格即时预检不回归；鼠标和键盘/装备共用入口。
- [x] 定向公开行为测试、客户端输入和Web实机回归及项目质量门通过。

## 范围外
非指向性技能追近、自动重试已开始后被取消的前摇、冷却/缺蓝时排队等待、技能数值或AI战术调整。
