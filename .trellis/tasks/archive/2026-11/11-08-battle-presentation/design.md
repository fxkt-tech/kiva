# 技术设计

## 状态与边界
模拟继续唯一拥有 HP、生命代次、死亡/重生、复活剩余时间。只增加必需只读 getter（death_tick 与 respawn_remaining）；原 UnitState/UnitPose/UnitLifeRef 已提供其余事实；不引入声音/模型句柄或第二套战斗实体。死亡事实要能处理一个显示帧跨越多次固定步甚至死亡→复活，旧生命不得覆盖新生命。保留既有 SimulationEvent 结构，音效在每个完整固定步后采集事件及当时身份/位置。

客户端拥有独立生命表现适配、资源装配、音效适配。死亡状态驱动倒地并保持最终姿态，UnitVisual 世界根仍唯一拥有位置/朝向/击飞高度；英雄尸体保持死亡坐标，不改变模拟半径或视野。普通暂停精确冻结，Finished 按已有 PresentationFrame 完成最后固定步一次，整局重开清理全部动态表现。

HUD 从 UnitState 的只读剩余秒数投影复活信息，JS 仅格式化和显示，不开计时器。死亡仍为 Active，不自动暂停或重开。

## 音效
使用独立模拟事件读者，采集实际出手/提交/生命事件，保存当时位置与生命身份，避免低帧率下查询到新生命位置。采集可放完整固定步后、玩法清理前，播放在客户端显示阶段；过滤团队观察并限制缓存寿命、优先级及并发。具体 AbilityId 和角色皮肤到音频 cue 的映射属于客户端内容，不进入 controls/simulation。
Web 使用薄 WebAudio 平台后端，Rust 唯一拥有 cue/事件筛选，可信进入/恢复按钮内 resume 同一 AudioContext。当前 Bevy 音频未启用、cpal 的 AudioContext 不公开，直接在 Update 调用不能证明浏览器手势解锁，故不为 Web 引入第二套原生 ALSA 依赖。原生通过同一只读事件适配验证 cue，不要求桌面声音输出。禁止 HUD 按 CD/按键猜测播放。音频准备、手势、暂停/失焦、重开清理需覆盖。素材使用已提取并校验的 Riot16.22.8348910 源计划寒冰和原皮皇子真实 SFX，经解码、事件层合成、音量/静音裁剪和 OGG 转码。音库来自固定 RMAN/WAD 段，scripts/fetch-league-audio.py 可独立复现；不以角色语音冒充战斗 SFX。

## 资源与动画
只读客户端外观映射负责角色/皮肤的模型路径、比例、标签锚点和动作绑定；技能图标/音效按实际 AbilityId 映射。皇子 Riot59 skin0、寒冰 Riot22 skin8（源计划），项目角色身份仍为现有1/2，不将 Riot ID 带进玩法。
离线转换为 Bevy 支持的本地 GLB/PNG/OGG；Trunk 显式复制 assets，不能依赖远程请求。导入保留完整骨骼动作，利用现有动作事实和 PresentationFrame 采样，不让动画根运动改写模拟位置。没有有效模型时保留现有程序模型，加载完成时原子替换，不能同时显示两套身体。
蒙皮模型命中须反映当前显示姿态，不能使用绑定姿态静态 AABB 替代此前真实模型检测。武器、躯干均可选；血条/特效/尸体不可选。
地图材质只更换表现纹理，UV/重复比例适配现有 MapDefinition；小兵资源按 UnitRole/Team 装配并共享句柄，不扩大规则范围。

## 风险与回退
皇子原皮与源计划寒冰的 GLB 已下载，均有完整骨骼/动画且仅标准 unlit 扩展；四种双方小兵 GLB 同样已验证。源计划隐形头/无人机 primitive 离线删除并压缩顶点引用，蒙皮命中只来自实际绘制部件。资源来源、版本、SHA256、处理命令统一落文件，避免不可复现二进制。原始地图贴图不是平铺地砖，必须通过 UV 选区适配现有中路。
按文件所有权分工，公共 mod.rs/Cargo.toml/index.html 接线由主代理合并；最终统一编译和浏览器验证，不并行运行多个重型 Rust 构建或 GPU 浏览器。
