# 第二版实施顺序

1. 在普通动作入口记录既有角色、镜头和连续输入的基准。由同一入口装配废站灰盒，按原机位检查移动、战斗动作、鼠标捕获和暂停。
2. 在原机位能清楚看见的积水旁放置立柱，接入实时反射。录下朱雀转身、挥击、横移经过柱子，以及镜头转过屏幕边缘时的反射。
3. 以绑定骨骼的全身女性模型验证反射层、深度、真实转身、主视图及阴影隔离。技术替身和青鸾正式角色分别验收。朱雀使用同动作对照，检查模型品质。
4. 交付上述连续实机录屏及模型转面图。审核操作、视角、模型和反射后再扩展可推镜架、车窗接力及相应动作。
5. 用实际游戏输入在原生和 Web 上复验，记录单个及多个可见映面的帧成本、构建和回归结果。

## 局外手卷

复用参考页的插画与交互，Web 接现有捕获、就绪和暂停流程，原生在 Bevy 内提供可操作的手卷。共享美术资源，选关与武器指令交给现有玩法和模拟。验收普通入口、直达链接、角色关系、两套武器、图录近景、补给购买、战斗中暂停回卷及模型查看器隔离。
