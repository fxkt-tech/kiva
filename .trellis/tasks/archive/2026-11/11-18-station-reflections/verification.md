# 第二版首幕实机验收

## 场景和角色

从动作游戏暂停卡片的废站入口或 `?level=station` 进入。原生等价入口为 `cargo run --locked -- --station`。朱雀与竹林共用角色资产、蒙皮、武器、输入和俯视机位。出生点的目标假人在站台远端，近水处可以自由转身。在目标距离外按 E 或 Q 会得到原战斗系统的条件不足提示。

青鸾使用独立的 `characters/qingluan.bin`。身体和基础骨架源于白灵淼，青色服饰、羽肩、羽冠和尾羽属于本次模型适配。可在模型验收页选择“青鸾 · 废站”和“无手持”，固定动作时间后切换视角。[模型实机转面](../../../../../art/station/qingluan-turnaround.webp)

## 可见性与输入

原生录像取自在独立虚拟显示器上运行的游戏窗口，使用鼠标和键盘事件。片中从出生点挥击，向右经过柱前，再向前、左、后绕回，转向并跳跃。向右时青鸾被柱子挡住，回程重新进入视野。[连续录像](../../../../../art/station/puddle-play.mp4) · [废站开场](../../../../../art/station/puddle-play.webp) · [竹林与废站的同模型、同机位对照](../../../../../art/station/camera-comparison.webp)

网页验收使用带窗口的 Chromium、临时静态构建和 WebGPU。通过实际输入捕获鼠标、转向、攻击和横移，离开积水视野再回头检查绘制，按 Esc 返回暂停卡片，点击恢复。

多映面连通、推镜架和车窗接力留待单水面试玩评审后制作。第一版截图和录屏作为历史记录保存。[第一版验收](verification-v1.md)

## 浏览器绘制采样

Chromium 使用 SwiftShader 软件适配器，游戏页视口为 960 × 600，设备像素比为 1。记录前台连续 18 个动画帧的间隔，并读取同一段 WebGPU 命令中的不透明场景 pass 次数。样本包括浏览器调度和场景绘制时间，两个采样点看向不同区域。

| 观察位置 | 每帧不透明场景 pass | 帧间隔中位数 |
|---|---:|---:|
| 出生点，水面在视野内 | 2 | 542 ms |
| 沿站台走出水面视野 | 1 | 358 ms |

沿原路返回后再次收到双 pass。上述数据用于确认实时绘制和离屏剔除，硬件 GPU 帧率尚待测量。

## 构建与回归

`make check` 完成原生 Clippy、Rust 测试（391 项通过、2 项忽略）、Node 回归（122 项通过）和 WASM 编译。WASM Clippy、临时目录离线 Trunk 构建以及 `git diff --check` 均通过。角色回归覆盖待机姿态、转头、装备蒙皮和开火时枪口闪光的反射层，固定步回归覆盖实际施放 Q 的 HUD 文案。网页和原生都保留原战斗施放条件。废站的标题、HUD、帮助和 Q 状态使用朱雀和青鸾的称谓。

## 局外绘卷实机验收

在 Chromium 中从部署子目录打开 Trunk 构建的完整游戏，依次翻阅六页。在武库装配斧弓后，人格页青鸾显示羿之影。百鸟图的灰鸦、秃鹫、雾鸮近景均能打开和返回。购买一份灰烬茶使羽晶从 1,380 减至 1,320，回卷后仍为 1,320。枯河无法出击，废站在首次渲染后可以获取鼠标并进入。战斗 HUD 确认装备斧，横移后按 Z 显示锤。Esc 暂停、返回手卷后武库显示锤，再出击成功捕获鼠标。测试期间没有页面异常或缺失的随包文件。

原生在 1440 × 900 的单窗口中验证六页、点选斧弓、购买、出击和 Esc 回卷。卷首标题显示「断轨听羽」，在此按 F2 后出击仍是原敌人模式。以 `--station` 直达，再返回绘卷、查看枯河、收卷选择「继续战斗」，成功回到原场景。网页和原生分别使用 Chromium WebGPU 与 Vulkan 软件渲染。网页版本保留预览水滴、墨迹和拖卷动效，原生使用同一批插画和单独的墨迹转场。[绘卷与战斗实机截图](../../../../../art/station/handscroll-in-game.webp)

本次 `make check` 通过 397 项 Rust 测试、129 项 Node 测试及 WASM 编译，原有 2 项 Rust 测试忽略。另检查了原生、WASM Clippy、Trunk 产物的相对路径、中文字体字形和 13 张共用原画。
