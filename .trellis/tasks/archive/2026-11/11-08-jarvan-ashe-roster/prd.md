# 皇子与寒冰角色及基础数值

## 目标
将现有旅者/秘术师换成皇子/寒冰，并将英雄与普通近远程兵数值统一到端游基础口径。

## 已确认要求
- 用户先询问两名英雄的属性、技能和一级/小兵数值，随后明确要求修改现有角色与单位属性。
- 皇子与寒冰使用一级裸基础值，小兵以未成长的普通近战/远程兵为基准；不继续使用自定义720/480生命。
- 沿用64地图、单中路、每分钟3+3/每0.5秒逐个出兵、基地胜负、整局重开和现有输入相机操作。
- 泉水最后配置仍为每秒最大生命/法力各20%（每0.5秒10%）。
- 用户后续已明确授权提交与推送；开发服务仍由用户管理。

## 实施前技术事实
- 当前CharacterId(1)=旅者、(2)=秘术师，内容集中在src/gameplay/content/。
- 当前模拟只有伤害/状态/位移效果，以及Impact/Dash/Channel执行；尚无护盾、军旗联动、临时地形或视野系统。
- 单位与技能空间使用世界单位，端游移速/射程不能直接以325/600原数字写入世界。
- 当前英雄没有等级、技能升级和自然生命回复字段；已有最大生命/法力、每秒回蓝与七项基础属性。

## 已确认技能范围
用户回复「一起替换」：两名英雄的被动和 QWER 一起实现，不能只改名称或继续绑定旧训练技能。
沿用当前四槽全部可用的对局形式：固定一级裸属性，四个技能均使用一级配置；本轮不加入经验、加点、成长或新装备体系。
寒冰 E 需要真实团队侦察；皇子 R 需要能阻挡移动的临时地形和二次释放拆墙。

## 验收标准
- [x] 选角与局内显示皇子/寒冰，预览、实例与HUD属性一致。
- [x] 一级英雄与近远程兵数值使用同一来源/口径，距离与速度有统一换算。
- [x] 角色与兵种构造仍走统一入口，控制/表现不直接修改战斗运行态。
- [x] 用户确认的技能范围得到真实行为验证，既有装备、暂停/重开与输入不回归。

## 范围外
提交与推送按用户明确授权执行，不接管开发服务；不加入等级/经济/防御塔/野区/联网；不新增暴击装备（当前暴击率为零）。
