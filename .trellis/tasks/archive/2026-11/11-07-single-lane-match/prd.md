# 单中路对局

## 目标
将试炼场升级为有胜负的单中路对局：玩家与AI各控制一名英雄，配合定期兵线进攻对方基地。
用户在方案与首波时间确认后要求继续，本任务进入实现；开发服务由用户管理，不自动提交或推送。

## 已确认要求
- R1 正方形世界地图，约现有常用视野一屏大小，仅有中路；默认观察视角下我方基地位于左下，对方位于右上。
- R2 用户明确纠正：一屏指地图尺度，不是改变玩法。保留现有边缘滚屏、缩放、锁定英雄、空格跟随及鼠标/技能操作，不强制固定全图相机或正方形画布。
- R3 任意基地生命值归零，本局结束。
- R4 每分钟出兵6个，组成固定为3近战、3远程。
- R5 玩家控制英雄，对方也有一名英雄；对方具备战术决策和技能施放能力。
- R6 沿用既有角色、技能、属性、六格装备及骨骼表现基础，保持可维护的代码架构。
- R7 用户确认开局立即出首波兵，后续出兵时刻为60、120、180秒等；暂停期间不计入对局经过时间。

## 本版实施规则（采用已展示方案，数值保留可调）
- P1 双方对称，每方每波6兵，均为3近战、3远程；按R7的已确认时刻生成。
- P2 基地没有自动攻击、不复活、不自回血；首版仅普通攻击本体可伤害基地，装备增加的攻击属性照常计算，技能/主动/被动附加效果不作用于基地。基地免疫控制和位移。
- P3 英雄沿用当前3秒后回己方基地满状态复活；小兵死亡不复活且及时清理模型。
- P4 双方英雄在各自基地附近、存活且脱战后可恢复生命/法力；同等规则作用于玩家和AI，速度可调。
- P5 同一模拟步双方基地都归零时判平局；终局后只展示结果和重开/重新选角，不再恢复旧局。
- P6 默认AI使用配置指定的现有角色，双方不额外获得隐藏数值加成；决策读取实际装配，不绑定角色名或技能ID。敌方初始无装备，暂不新增装备购买AI。
- P7 按追加调整，默认地图边长64世界单位、基地3000生命/20护甲；近战兵720生命、远程兵480生命。全部是未经过平衡测试的调试起点。

## 范围外
防御塔、野区/多路、经济与经验、等级成长、商店购买、新角色新技能、战争迷雾、联网、完整硬碰撞卡位；本轮不修改现行规范以假定这些功能已经存在。

## 验收标准
- [x] AC1 两基地和单一中路可辨识，地图和碰撞/小地图同源；默认镜头投影满足基地左下/右上；原相机交互和高DPI拾取保持可用。（R1/R2）
- [x] AC2 普攻能合法损伤基地且生命只有模拟路径写入；控制/位移不会移动基地，所有技能/装备来源遵守同一结构受效规则。（R3/P2）
- [x] AC3 开局立即生成首波，每波每方恰好3近战3远程；后续60秒边界、暂停恢复、一个显示帧多固定步无重出/漏出；终局当步不再生兵。（R4/R7/P1）
- [x] AC4 小兵会接战并在清敌后继续推进；近战直接命中，远程实际弹丸；不因频繁改目标或拥挤而持续取消攻击。（R4）
- [x] AC5 AI能推线、判断交战/撤退/守家、按实际技能定义瞄准和释放；遵守法力、CD、控制与前后摇，有有限反应时间且不读取玩家未来输入。（R5）
- [x] AC6 暂停冻结对局时钟、兵波、AI和已显示姿态；基地归零产生一次结果，同步最终状态后冻结，恢复捕获不能继续旧局。（R3/P5）
- [x] AC7 英雄死亡重生清理旧AI目标；小兵死亡清根及子模型且已提交效果继续；重开/重新选角清理波次、AI、效果和旧请求，保留单调身份分配。（R6/P3）
- [x] AC8 173项既有测试继续通过，新增无窗口模式/AI/结构/兵线测试及Web地图布局/技能/血条/相机/重开回归；长时间出兵不积累隐藏尸体。（R6）

## 方案评审状态
出兵时刻已经用户确认并纳入R7；用户随后要求继续，按本版规则实施。初始数值按实际验证调整，提交/推送需后续明确授权。
