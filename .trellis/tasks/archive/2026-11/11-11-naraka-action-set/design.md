## 数据流与所有权

    客户端原文件（只读）

      └─ Wwise PCK / HIRC / DIDX
           → 事件到媒体解析 → 小范围媒体转码 → 音效与来源清单

    可信输入 → CombatIntent / ActionIntent
      → 60Hz 模拟：段数、时钟、marker、防御阶段、实际运动事件
      → 只读动作快照 + 单调事件序号
      → 客户端动作映射 → 共享采样/重定向 → 实际皮肤与武器挂点
      → 客户端音效映射 → Web Audio

    模型检查页 → 相同动作映射 / 采样 / 皮肤 / 挂点（受控单体重放）

simulation 不知道源 clip、曲线名、WEM 或浏览器；gameplay 不生成骨骼。动作和音效不能驱动物理位置或扣血。原动画根位移仅作为来源保留；运行时平面位移仍来自 Body，跳跃竖直位移也不叠加两次。

## 三段普攻规则（Kiva 适配）

1. 每个左键实体按下仅请求一段；按住不自动三连。成功接受按 1→2→3；每段独立 action_id，hit_index 仍为本段的0。
2. 第1/2段活动期间最多缓存一条后继普攻。多次点击只保留一次；第3段不缓存第4段。
3. 当前段全部 marker 结算后，下一固定步按原准入条件消费后继。不满足准入则丢弃，不绕过冷却、防御、闪避或死亡。
4. 无缓冲时，当前段结束后保留0.45秒后继窗口；窗口过期或第3段结束回第1段。窗口只随模拟时间推进。
5. 有效 E/Q/Tab、防御、闪避、普通跳跃、换组、F2模式替换、死亡/复活重置后继。普通受伤清掉未承诺后继，当前攻击按原规则完成；本次不新增硬直打断系统。
6. 失锁/失焦清未承诺后继，已承诺攻击仍按现有暂停契约冻结；恢复不能出现旧缓存自动续段。清理请求需要锁存至模拟消费，不能被暂停期间无固定步丢掉。
7. 初版保留现有武器的每段伤害/距离与总时长：锤24/2.8m/0.60s，链斧18/2.6m/0.40s；初始 marker 分别0.12/0.08s。三段均为普通攻击，不增加第三段霸体、破防、伤害加成。
8. 原片段按阶段单调映射到上述时钟；原接触帧若有配置证据则引用，否则由离线姿态检验选取并明确标注为 Kiva 适配锚点。禁止把该数值描述为永劫原命中规则。若验证发现当前时长严重损害辨识度，必须在实施记录写明调校值与理由并同步模拟测试，不能只在显示层换一套权威时间。

公开 MeleeStage::{One,Two,Three}，不可变 stage 存入 ActionSnapshot/HitContext/CombatEvent。私有 MeleeChain 管理 next/grace/buffer，不复用 E/Q/Tab 的 ComboWindow。增加明确普攻起手事件供长音色从动作起手播放；原 Melee marker 继续负责挥击特效/伤害，不重复播音。

## 右键阶段与声音

DefenseSnapshot 提供当前kind/阶段经过时间，以及持久保留的last_gesture_kind、gesture_id和gesture_elapsed；动画不再只读is_active。显示帧即使跨过完整0.18秒弹反窗，也能从不可变手势身份恢复曾经发生的Parry，不能只看当前Idle。

| 实际阶段 | 动作 | 声音触发 |
| --- | --- | --- |
| Deflect | 横刀振刀起手 | 仅在找到独立预备音时播放一次；真正成功声只读 Deflect 结算 |
| Waiting | 同源收势/兼容持势 | 无成功声，不能表现为已有格挡减伤 |
| Guard | 振刀已验证持势帧保持 | 不循环整段音频；Block 结算时一次金属碰撞 |
| Parry | 按用户要求使用振刀成功动作 | 动画是用户指定映射；只有真实 Parry 结算播放成功音效/特效 |
| Idle | 收势回当前移动/待机 | 不制造释放弹反 |

保留原拆招/等待/防御/弹反判定、正面条件、耐力和冷却。短按右键仍不能凭动画生成弹反；成功反馈不得把同一次基础振刀重启到0秒。

弹反0.18秒是权威判定窗，不能把原1.833秒反击片段全部挤进该窗口。首版使用0.60秒纯表现手势（含0.18秒窗后的0.42秒可打断收势）；具体源播放区间/phase锚点在H0转换验证后的姿态检查确定，源片段对照仍保留完整原时长。手势由gesture_id只起一次，归共享RigPose管理；死亡/受击和新接受攻击、技能、防御或实际移动/闪避/跳跃可抢占，不能阻挡已合法的模拟输入。暂停/HitStop冻结与游戏RigPose一致；真实Parry反馈只加一次声音/特效，不再重启手势。该0.60秒及区间适配是Kiva设计，不宣称原游戏时序。

## 动画来源与共享重定向

原clip的缺通道必须区别于数值0：已读片段有55/59/75/95个muscle，横刀待机可能缺一侧20指通道，跳落循环与部分远程仅55身体通道；原override另有横刀/弓左右手默认指层。离线准备保留main authored mask、默认层身份和原layer顺序/权重证据，先组合再转换/烘焙。顺序/权重未知项不得猜成原规则；最终按本文件实施补充的显式Kiva优先级组合，不用零值/导入握拳补齐。为不同weapon/controller上下文烘焙同一共享clip时，保留组合身份；查看页trace明确实际默认指层，不能把组合后的成品称未加工单层原片段。H0至少检查attack95、idle75、jump-loop55及各自双手，单个全95攻击通过不能代表缺轨动作也正确。

新增显式SourceRig::{Yanyun,Naraka}和包含来源的clip身份（这里的rig标识实际已烘焙骨架，不只是游戏品牌；首套Naraka采用已证男性63节点完整骨架/53节点human映射，若另用女性donor必须新增独立rig身份和binding，不能仍复用同一数组），SourcePose 同时带 rig 与矩阵。旧燕云与新永劫分别维护自己的原名、父序、rest及采样缓存；不得把新片段改名为燕云节点或填充成986骨。

每套目标资产为每个 donor 缓存 MotionBinding：23语义驱动、源rest、原生palette适用关系、独立指链和真实掌框。直接全palette仅用于确实相同原生骨架的路径；同名骨也必须比较原rest。哥哥F3换成愁铃客外观仍使用玩家永劫动作，Boss保留燕云源片段。妹妹先匹配实际有证据的枪/弓姿态，维持已有双手握点IK优先级和Q/Tab时序；不能用近战动作覆盖远程瞄准。

不同 rig 的 source_local/from 不能 zip 混合；来源切换重建本来源历史，经目标姿态过渡。当前手部修复继续生效：目标自身臂/指长度、参考臂向最小摆动校准、真实腕/MCP掌框、独立三节指局部quat混合后FK、原IBM/rest冻结、+0.055m语义偏移与正确柄头方向。

动作资产子任务第一道门槛H0是Humanoid转换：准确读取streamed/dense/constant与95肌肉、原Avatar pre/post/sign/limits、root和必要IK/twist；不能以generic附件运动当身体动画。现有数学spike明确缺少native twist分摊、Body COM到Pelvis和IK，非原生oracle。H0必须在批量烘焙前取得同版本Unity离线采样/经独立验证的完整转换器或等效逐帧真值；建议同rig对照local quat≤0.1°、腕/指及真实LBS顶点≤1mm，阈值调整需记录实测依据。当前常用位置/注册表未发现Unity原生求值环境，这是实际技术依赖，不假定已有或已安装。H0未过仅交研究/准备成果，不批量宣称动作可用、不切游戏默认。

## 音效与生命周期

每个 cue 保留 event/action/container/media、所用原变体及源 SHA。原动作轨已直接关联三段音频event；源time数值保留，单位未恢复前不得标为已知秒或归一时间。以实际普攻起手建立一次性声音调度，按最终证明的轨道语义映射偏移；若使用Kiva适配偏移须单列，历史过期cue丢弃而非补一串延迟音。原挥击媒体包含起手衣料和尾音，播放完整自然音高，不跟动画倍率变调；命中声只读 Hit，挥空没有 impact。防御响应按 defender 身份选音，不能拿历史攻击者 pair 误认防守者武器。

延期声音的最小合同：权威MeleeStart事件固定actor/source_owner/action_id/pair/stage/sequence；客户端PendingActionCue保存该身份、cue、Kiva偏移at及过期阈值。只以当前同一ActionSnapshot.elapsed判断到点，不以显示dt累计第二份攻击时钟；当前action身份不符、死亡、失锁、有效取消或换组时清掉未发cue。到点最多播放一次，迟于at+0.12秒的旧cue丢弃，最多为当前动作保留两条待发cue；不能在低帧率下给已经结束的前两段补一串声音。偏移未验证前默认0秒并显式标Kiva适配，不将原未知time直接当秒。JS桥仍只播放当下到点的白名单cue，不存跨暂停延迟队列。

先覆盖三段挥击、命中、拆招/格挡/成功弹反、起跳/实际落地/闪避。脚步按已证明的音源switch选择，并由接地且实际物理位移累计距离触发；堵墙、空中、传送/复活不发脚步。跳跃/落地/闪避起手由真实接受和接触转换产生 MotionFeedback，不能把按键当成功，也不能复用 CombatEffect::Dodge（该事件表示攻击被无敌躲过）。

原落地事件含两个并行PlayAction，必须保留各层并独立选择原变体；不能只导出首个Sound并称完整事件，也不预制全部变体的笛卡尔积。每层播放均计入底层声部预算。

Web只接收有界语义cue，使用白名单同源文件、可信手势解锁、缓存decode和独立事件游标。未解锁/解码失败/暂停事件丢弃并推进游标，恢复不补播。保留BGM、妹妹鸟铳/弓的独立射击行为。振刀轨目前只有共享金属碰撞候选，没有独立预备声时空振保持静音，不借成功碰撞声冒充起手声。现有4声部基础上加明确关键声优先级，脚步先让位于命中/成功防御；必须检测最大叠加峰值，不直接叠加所有变体。当前无用户音量UI，本次保留失锁静音与固定安全增益，不新增音乐/音量设置面板。

- 每个准备包独立--verify：冻结包含源对象/曲线/骨架证据、H0验证后的baked locals与音频转码来源；普通verify无需Windows安装，可核SHA/结构并从冻结locals重新打包比字节。原曲线/Avatar→原生姿态的--rebake是另一操作，需要记录并提供同版本求值工具/环境；不能把verify打包校验说成已完整重跑Mecanim。若最终完整纯离线converter可取消外部依赖，必须实际证明后再合并命令。
