# 狼人领头人夜间战术讨论

## Goal

将当前“第一名存活狼人代表狼队直接选择刀口”的夜间流程，改造成由主理人在第一夜指定一名狼人作为初始战术制定者、狼队成员围绕当夜局势展开私密讨论，并在后续夜晚以平等身份协同行动的流程，使多狼人行为具备协作感、角色差异和可编辑的创作过程。

## Background

- 当前每夜只创建一个 `wolf_kill_selected` 草稿，行动者固定为存活狼人列表中的第一人，默认目标是第一个合法的存活非狼人玩家（`src/core/advance-planner.ts:182-218`）。
- 狼刀目标必须是存活的非狼人玩家（`src/core/rules.ts:100-111`）。
- 狼刀草稿可由主理人手动修改目标，或通过 LLM 重新生成；确认后成为正式事件（`src/server/game-actions.ts:193-238,243-270`）。
- 狼人行动使用狼人的私有视角生成，并以狼阵营私密事件保存；当前没有狼人逐个发言、讨论上下文或团队共识事件。
- “主理人”目前是游戏级主持人快照和台词呈现者，不是玩家，也没有既有的“指定行动者”领域模型。

## Requirements

- 主理人必须能够在第一夜从存活狼人中指定一名领头人。
- 领头人选择是 Editor 内的主理人控制步骤，Preview 不为“选择领头人”提供特殊画面或公开叙事。
- Preview 在第一夜不解释领头人如何产生，相关内容直接从领头人发布初始战术开始。
- 领头人的特殊职责仅限第一夜制定狼队初始战术；第二夜起其权限与其他狼人完全相同。
- 领头人死亡后不补选，也不影响既有初始战术作为历史上下文继续存在。
- 夜间狼刀前，多个存活狼人需要产生狼阵营私密的讨论内容。
- 每夜分为“发表意见 → 狼队投票 → 确认刀口”三个阶段。
- 第一夜在常规三个阶段之前额外增加“领头人制定初始战术”阶段；这是第一夜和后续夜晚的唯一流程差异。
- 第一夜初始战术发布后，其他存活狼人依次发表意见；领头人不在意见阶段重复发言。
- 第二夜起，不再产生新的领头人战术，所有存活狼人按常规方式发表意见。
- 所有存活狼人（包括第一夜的领头人）随后参与等权投票，每人一票；领头人没有双票权，也不能绕过投票单独决定刀口。
- 狼队投票采用密票：投票者能看到当夜已确认的初始战术和讨论意见，但不能看到其他狼人当夜已经投出的票。
- 所有存活狼人完成投票后，系统才汇总并展示计票结果。
- 结票记录包含每名狼人的具体投票、各目标总票数以及最终刀口。
- 唯一最高票目标成为当夜刀口；多个目标并列最高票时必须暂停自动流程，由主理人在 Editor 中从并列目标里人工选择并确认，AI 不得生成或推荐裁定目标。
- 狼人讨论顺序必须确定且可复现；首版不提供多轮自由对话。
- 第一夜领头人在其他狼人发表意见之前输出初始战术；战术是后续意见和投票的狼队共享上下文。
- 最终刀口仍须满足现有合法性约束：目标存活且不是狼人。
- 讨论、领头人战术和最终刀口必须保持狼阵营私密，不能泄漏给好人玩家或公共回放。
- 导演/主理人 Preview 必须展示第一夜初始战术、每夜狼队讨论过程以及最终结票内容。
- 所有 AI 生成结果继续采用“草稿 → 主理人检查/编辑 → 确认事件”的可控工作流。
- 夜间守卫、预言家、女巫及死亡结算规则保持兼容。

## Acceptance Criteria

- [ ] 主理人可以明确选择合法的存活狼人作为领头人，非法或已死亡玩家不能被选中。
- [ ] 领头人的特殊职责只在第一夜生效；第二夜起不再拥有优先发言或最终拍板权，死亡后也不会出现补选步骤。
- [ ] 存活狼人会在最终落刀前按确定顺序形成可审阅的狼队讨论记录。
- [ ] 第一夜先产生一份由领头人撰写、可审阅和重新生成的初始战术；该战术独立于目标票保存。
- [ ] 第一夜除领头人外的每名存活狼人最多产生一条已确认意见；第二夜起每名存活狼人最多产生一条已确认意见。
- [ ] 每名存活狼人每夜最多产生一张目标票，包括第一夜的领头人。
- [ ] 第一夜最终刀口由狼队计票产生，而不是直接采用领头人的目标票。
- [ ] 计票按每名存活狼人一票计算；唯一最高票自动进入最终刀口草稿。
- [ ] 任一狼人生成或编辑自己的票时，其上下文均不包含其他狼人当夜的投票选择。
- [ ] 所有票确认前不生成或泄漏局部计票结果；全部确认后才生成狼阵营私密的完整计票记录。
- [ ] 平票时最终刀口草稿只允许主理人从并列最高票目标中选择，不能选择未并列的其他玩家。
- [ ] 平票裁定草稿不触发 LLM 自动生成或重新生成功能，未人工选择并确认前不能进入夜间后续流程。
- [ ] Preview 结票画面同时展示每只狼的具体票、各目标票数、最终刀口；平票裁定后能标明人工裁定结果。
- [ ] 确认最终决策后，夜间结算仍正确处理守卫守护、女巫解药和毒药。
- [ ] 非狼人视角及公开播放不会看到领头人身份、狼人讨论、战术或未公开刀口。
- [ ] 第一夜仅有一名存活狼人时，流程自然退化为其独立制定初始战术，不产生无意义的自我讨论。
- [ ] Editor 在第一夜战术生成前提供领头人选择控件，并限制候选人为存活狼人。
- [ ] Preview 不为领头人选择步骤生成独立场景、主持人口播或特殊视觉标记。
- [ ] 第一夜 Preview 的首个狼队协作场景是领头人发布初始战术，后续按事件顺序展示其他狼人意见。
- [ ] 每夜 Preview 展示狼队讨论过程，并在全部密票完成后展示结票结果。

## Scope Notes

- 本任务需要新增或扩展夜间事件/草稿契约、规划器、LLM 生成上下文、主理人编辑界面、可见性及回放测试，按复杂任务规划。
- 暂不改变狼人合法刀人范围以及守卫、女巫对刀口的结算语义。
- 不考虑旧游戏数据兼容、迁移或旧事件回放；允许直接收紧或替换现有狼刀相关契约。
