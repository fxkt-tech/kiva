# 游戏模式发言预算与上下文压缩

## Goal

不改变狼人杀规则、行动、投票、胜负和视频内容选择，通过生成阶段的发言长度合同与确定性上下文压缩，把样本局导演版从 76.04 分钟级降到 28–32 分钟，并为后续剧本模式提供共享时长模块。

## Background

- 父任务：07-12-game-duration-theme-integration。
- 样本局共有 105 个导演场景、76.04 分钟；LLM 发言约占 94.8%。
- 白天发言平均 548 个非空白字符 / 90.6 秒；后期 Prompt 从第一天平均 4,398 字符膨胀到第四天 23,741 字符。
- 当前任务规格没有长度合同，speech parser 只要求非空，知识区使用粗粒度 40 × 800 上下文预算。

## Requirements

- 建立单一 speech-budget 模块，拥有五类 speech Draft 的目标区间、硬上限、最低有效表达、字符计数和语音时长估算。
- 人物风格只能在预算内改变节奏，不能扩大上限。
- Prompt 要求保留结论、一个关键依据和一个后续验证点，禁止完整时间线/票型复述、前置观点复读和括号舞台动作。
- 超长完整 JSON 使用现有唯一 repair 做语义压缩；仍超长则保持 Draft 不变。不得字符串截断、音频裁切、视频倍速或粗暴 max_tokens。
- 人工编辑和确认复用同一硬上限。
- 上下文集中选择当前日、上一日结算、每名玩家最新立场、未解决身份/查验冲突和本人有效私有记录；票型使用结构化摘要。
- visibility 继续是知识边界，压缩不得泄漏 host-only、密票或他人私有事件。
- 游戏模式的行动、投票和规则行为完全不变。
- 显示当前已承诺导演版时长、预计区间和预算档位；理论极端长局明确告警，不静默裁切。
- 不覆盖样本 record、voice jobs 或 MP3；重放使用临时目录。

## Acceptance Criteria

- [ ] 只读诊断可复现样本 105 个导演场景和约 76.04 分钟构成。
- [ ] 所有 speech Draft 都有共享长度合同，测试覆盖 Unicode 与边界值。
- [ ] 首次超长只触发一次压缩 repair；二次失败不确认截断文本。
- [ ] 当前日关键推理、公开身份冲突、遗言和票型依据在压缩后仍可用。
- [ ] visibility 负向测试证明上下文压缩没有泄密。
- [ ] 游戏模式行动、投票、角色规则和胜负回归不变。
- [ ] 样本 57 个发言局面重放后，预计导演版落入 28–32 分钟且不超过 35 分钟。
- [ ] 相关测试、typecheck、test、build 和 diff-check 通过。

## Out of Scope

- 单局剧本、双模式 New Game、导演 Review 或动态章节旁白。
- 改变狼人杀规则或为时长强制结束游戏。
- 覆盖现有样本数据和语音。
