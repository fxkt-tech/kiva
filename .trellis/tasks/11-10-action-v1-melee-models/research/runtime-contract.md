# 近战运行资产合同

## 已固定的运行接口

- `assets/fulangmao/weapon.bin`：伏浪锚，物品 2310478，锤类显示。
- `assets/zhexingcuishan/weapon.bin`：谪星·摧山，物品 2311638，链斧显示；手持与离手飞行复用同一缓存。
- 两者严格使用既有 `KIVAWP01`，magic、来源 JSON 长度头、AV03 材质表、6f32 握点、部件表不变；顶点为位置／单位法线／UV 共 8f32（32 字节），索引为 u32。数字小端，字符串 u16 字节长度＋UTF8。
- 所有部件均 `mount=0`，对于近战表示 Grip：右手握点／根原点 `(0,0,0)`，长轴从柄朝头为 `+Y`。根使用单位变换，已有近战手腕校正负责世界朝向。第二个握点同样为零，仅为格式保留，不驱动近战 IK。
- 来源 current-LBS 与原静态节点层级先求值，再烘焙刚性显示网格；不以 inverse(IBM) 代替当前骨姿态。骨序和原 IBM 仅在来源／数值报告保留，不新增运行时骨骼或 GLTF 依赖。
- 原基础色 RGB、alpha、UV、材质色因子、cutoff、doubleSided 保留；基础色 PNG sRGB，至多 1024 像素。未知 normal／packed／Float／flow 不接为颜色或 ORM。
- 每组随包 `README.md`、`source-manifest.json`、`conversion-report.json`；新脚本 `scripts/import-melee-models.py --verify` 在临时目录重建四文件逐字节对比。

## 源轴、握柄与尺寸

伏浪锚原 current-LBS 边界 `(-0.094983,-0.346256,-0.687742)` 到 `(0.094983,0.346256,1.931365)`，原长轴为 `+Z`。
选择源 `(0,0,0)` 的细柄中心作为 Kiva 握点，绕 X 轴 -90° 后统一缩放到 1.10m 长；这是显式手持适配，不冒称恢复原 Actor 挂接。
包含主体 4989 顶点／7252 三角形（5 骨槽）及附属 448 顶点／586 三角形（原 UInt32 单索引、implicit weight1），共两件网格／两个材质；不丢失原四权重或附属几何。

谪星的原主件同样沿 `+Z`。独立输入在原 controller 中属于刀刃、刀背、人头、刀柄及 FX 组；[source-evidence.md](source-evidence.md) 已证明四个非 FX 输入互补，且原静态层级为原点附近的独立小形状，直接叠加不能形成完整原作刀形。
本次选择主杆加四个非 FX 原件，以明确的 Kiva 部件变换组成一份静态外观；两个 FX 输入排除。没有采样 Float／packed 形变数据，也没有把预览 PNG 用于几何。

`A_piece = Translation * Rx(+90°) * Scale`，以下数值均在原 current-LBS 世界空间；主杆 `A=Identity`。逐件完整 4×4 矩阵和组合矩阵同时写入两份 JSON 报告，未更改原顶点／索引／UV 或 source GLB。

## 已完成的离线验证

`scripts/import-melee-models.py --verify` 已通过：两组各四文件临时重建逐字节一致，源包所有清单文件／哈希在转换前后验证，三个复用 helper 的哈希固定，未改旧转换器或旧资产。
验证逐骨原 current-LBS、全部实际权重槽、448 单索引原字节及 implicit weight1、原索引／UV、单位法线、每个基础色 RGB／alpha 像素完全一致、原材质响应和 binary EOF。
7 种损坏输入（截断、尾字节、magic、超长头、非有限位置、越界索引、错误 mount）均拒绝。

实际 f32 网格的最近顶点对给出部件表面间隙上界，2mm 容差图中所有部件连通；谪星主杆连接刀背 0.678mm、刀刃 1.142mm、柄饰 0.486mm，人头连接刀刃 0.554mm／刀背 0.742mm。该检查不声称拓扑焊接或精确三角形相交。
主会话已查看实际二进制的 CPU 部件色侧投影，接受本次明确的静态组装；它不是 GPU、原 shader 或浏览器画面验收。

## 选型边界

尺寸、握点与已有近战手腕的方向适配属于 Kiva；不改变 simulation 攻击距离、碰撞、伤害、飞行轨迹或相机。
谪星只交付一份来源可解释的静态外观；随机星格、溶解、灵光、反射 cubemap 和完整原作 shader 不在本次运行效果中。
