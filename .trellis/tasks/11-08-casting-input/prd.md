# 普通与智能施法、技能后的移动意图

用户已批准直接实现，沿用上项要求：架构规范、普通代码测试，不运行浏览器测试，不启停服务；未授权本轮提交推送。

## 功能与验收

- 默认QWER智能施法：按下键以当时鼠标的模型候选/方向/地点提交一次，不需左键。1–6主动装备遵循同一模式。
- 暂停/选角菜单支持普通与智能施法切换并保存本地偏好；Shift+技能键临时使用普通施法。
- 普通施法按键显示原指示器，左键确认，右键取消并执行原移动/攻击。鼠标点击技能/装备图标继续进入普通瞄准，自身/重施技能直接释放。
- 两种模式复用目标资格、指示器和模拟命令。Enemy超距追近、Direction按方向、Point按已有最大范围策略；非法目标/缺蓝/冷却等不能绕过规则。
- 键盘智能施法使用按键时的鼠标坐标，不使用上一帧或后续鼠标位置；UI手势、失焦、捕获/暂停边界和重复keydown不能泄漏技能。
- 修复施法后回走旧目的地：成功提交的新施法终止旧MoveTo/AttackMove目的地；普通非位移技能可保留明确普攻/持续普攻意图。真正开始自主Dash/Leap时清除旧追击意图；Link按用户追加要求建立无旧目标的AutoAttack，落点附近自动攻击，不恢复旧远处追击。敌方强制位移不改变原有意图恢复规则。
- 用户追加的快速EQ与后续普攻要求、复现和方案见[eq-followup.md](eq-followup.md)：同tick不能Busy丢Q，已部署未落地的自己军旗可连接，伤害/光环/视野仍按原落地时钟。
- 拒绝的施法保持原有效指令、资源与动作。技能前后摇、CD、提交校验、新命令取消等保持既有规则。
