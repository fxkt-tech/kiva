# 战斗外界面：风格样张与技术方案

## 已确定的决定（用户确认）

- **风格**：参考《少女前线2：追放》的界面写法，不照搬其美术、图标、文案和版式。
  - 场景或立绘铺满画面，界面浮在上面。主菜单是右对齐的纯文字（首项最大，带强调竖杠和小编号），左上是活动横幅列，左下是圆形按钮、工具行和资源，底部是图标加文字的入口，右下是促销横幅。
  - 方角平面块，半透明炭黑面板；选中状态用浅色实底；白色粗黑体带阴影；强调色只用在主操作的实色块上。
- **纹理**：不使用纸张纹理（已试过，用户决定去掉）。界面块是纯色平面，标题保留墨迹效果。
- **配色**：废土的灰烬、水泥、炭黑；朱雀（主角）用朱红、焰橙、金，金只用于稀有度和星级；青鸾（姐姐）用青绿，负责引导和选中。不用米黄色。
- **分辨率**：自适应分辨率。界面铺满整个窗口，不加外框和黑边；设计基准 1920×1080，最低 720p，向上支持 2K、4K，只做桌面。界面内容（尺寸、间距、字号、位置偏移）全部按窗口尺寸等比缩放。
- **实现**：Tailwind v4 加原生 Web Components（light DOM），不引入 React 或 Node 工具链。Trunk 0.22.1 的 `rel="tailwind-css"` 默认使用 Tailwind 4.3.3，构建产物是静态 CSS。

## 技术方案

1. **自适应**：根字号 `min(100vw / 120, 100dvh / 67.5) × --ui-scale`，1080p 下为 16px，720p 下 0.667 倍，2K 下 1.333 倍，4K 下 2 倍。所有尺寸和偏移都用 rem（Tailwind 的间距和字号本来就是 rem），因此整套布局等比缩放；比例不是 16:9 的窗口按较紧的一边缩放，元素锚定窗口边缘。1px 的细线保持 1px。
2. **字号下限**：`@theme` 重新定义字号档位，最小档为 1080p 下 18px（720p 下 12px），不提供更小的档位。
3. **布局**：界面元素锚定窗口边缘，偏移量用 rem；背景场景按窗口尺寸绘制并铺满。
4. **组件**：用 `customElements.define("kv-*")` 定义组件，渲染在 light DOM 中，内容由属性提供。状态一律用 `data-*` 表示，配合 `group-data-[…]` 写样式，JS 里不拼接类名，方便 Tailwind 扫描。
5. **特殊效果**：墨迹（`ink`）、文字阴影（`shade`）用 `@utility` 定义，尺寸用 rem；墨迹滤镜参数随根字号缩放。
6. **美术资源**：图标用 SVG；位图按 4K（2 倍图）准备。

## 本任务范围

- 用以上方案改写 `paper-ui-preview.html`（主界面和出击选关）。样张阶段用 Tailwind 浏览器版，便于反复调风格。
- 不接入 Trunk 构建：首次构建需要联网下载 Tailwind 程序，由用户处理。
- 不迁移战斗 HUD：作为后续单独任务，需先把动态类名改为 `data-*`，并同步修改 Node 测试。

## 验收

- 在 1280×720、1920×1080、2560×1440、3840×2160 下界面等比缩放，不超出屏幕，最小字可读。
- 页面中没有 `cqw` 和固定像素字号；所有颜色来自 `@theme`。
- 风格由用户在浏览器里确认。
