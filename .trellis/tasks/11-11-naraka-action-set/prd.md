# 永劫无间横刀动作、三段连击与音效

## 目标

从用户本机永劫无间客户端解析动作与对应音效，改善哥哥三段左键攻击、右键拆招/防御/弹反和常规运动表现，并能在已有模型检查页验证角色、手指、武器与动作是否正确。

## 背景与已确认事实

- 用户指定客户端：C:\Program Files (x86)\Steam\steamapps\common\NARAKA BLADEPOINT；WSL路径/mnt/c/Program Files (x86)/Steam/steamapps/common/NARAKA BLADEPOINT，目录已可读。
- 原状态/override/combo配置已证横刀101→102→103分别映射attack_light_01/02/03；原第三段包含更强战斗规则，但本次仅借动作，不引入霸体/破防等机制。
- 已读取原AnimationClip与Avatar：身体/手指主要为Unity Humanoid muscle；原53节点human骨架含30指节。部分通用动作只带55/59/75通道，必须恢复原左右手默认层，不能把缺轨补零。
- 17个原Wwise事件媒体链已解析，每个事件首变体已真实解码/转Ogg；三段/振刀/运动的声音关联有原轨道证据。原轨time单位、部分switch名及全部Wwise总线行为尚未恢复。
- 规划时的代码普攻只有单段，攻击中点击丢弃；右键模拟已有分阶段，显示却只取is_active。现有源姿态索引绑定燕云骨架，不能直接换成永劫矩阵。
- 研究和来源范围见research/animation-assets.md、audio-assets.md、humanoid-conversion.md、runtime-combat-integration.md；未来方案不进入canonical specs。

## 验收标准

- A1：每个采用的片段/声音都有原路径、对象或event/media、哈希、工具/版本和语义证据；普通verify与需要原生求值环境的rebake区别清楚。
- A2：真实固定步和真浏览器输入都可1→2→3；单击不自动三连，狂点不堆无限动作；各段独立身份/单次marker，空挥/遮挡等原结算规则保持。
- A3：Deflect/Waiting/Guard/Parry可分别检查，长按不循环整段发声，短按仍不能生成弹反；空弹反无成功金属声，真实成功只一次。0.18秒判定不被视觉手势延长。
- A4：逐状态映射有事实等级和回退说明；无法确认的片段/原时序不得改名冒充已恢复。Boss原燕云行为保留，妹妹现有技能事实和握点优先级不变。
- A5：李火旺、愁铃客玩家、白灵淼的真实palette/加权顶点与左右掌/五指通过检查；原rest/IBM不改。查看页暂停/seek/角色与来源切换复用游戏计算，不加只在查看页生效的纠偏。
- A6：音效按真实起手/命中/防御/运动事实触发，无每帧重播；落地并行层保留，脚步不在堵墙/空中/传送发出；失锁静音，恢复不补播，原媒体自然音高和声音预算有测量。
- A7：H0先取得可信原生/独立完整转换对照，覆盖95攻击、75待机和55跳落循环及其指层/root/twist/IK；不能以非零肌肉/手指运动通过。实现后的导入verify、make check、WASM Clippy、临时Trunk与有界面浏览器检查通过；软件/真实硬件GPU验收分开记录。
