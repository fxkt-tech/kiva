# 三维物理迁移与非平地测试场景

## Goal

让当前庭院中的角色、箱子和地形遵循一致的三维碰撞、重力和支撑规则，消除箱子被视为无限高墙的问题，并提供坡道与小山供用户测试非平地操作体验。保留现有二段跳、闪避、疾跑、蹲伏、滑铲和武器联动玩法。

## Background

- 当前水平位置为 Vec2，跳跃高度单独存储；静态碰撞不接收高度。证据：`src/simulation/movement.rs:9`、`src/simulation/movement.rs:103`、`src/simulation/geometry.rs:5`。
- 关卡的三维尺寸在碰撞装配时只保留 x/z。证据：`src/gameplay/mod.rs:70`。
- 视线查询与部分战斗范围仍使用二维距离。证据：`src/simulation/combat.rs:336`、`src/simulation/combat.rs:477`。

## Requirements

### R1 — 统一三维运动与接触

- 玩家和敌人具有真实体积，水平 / 竖直运动统一参与碰撞。
- 能跳过足够低的障碍、落在箱顶或平台上，走出支撑边缘后自然下落；撞击物体侧面、底面时不能穿透。
- 接地根据当前支撑接触判断，不能继续把世界高度等于零当作唯一落地条件。
- 跳跃次数在有效落地时恢复；在空中暂停、输入清理或击飞不能额外恢复。
- 角色保持直立和明确的操作方向，模型与相机读取同一份物理结果。
- 蹲伏缩短实际碰撞体；起身时头顶净空不足则保持蹲伏，不能穿入上方实体。

### R2 — 动态箱子与固定场景

- 箱子有质量、重力、摩擦及转动，能够被角色推动、碰倒、堆叠并稳定停留，也能支撑站在其上的角色。
- 地面、石柱、石块及地形作为固定实体参与同一套物理碰撞。
- 场地边界按可见围墙的实际高度碰撞；越过边缘跌出场景时使用既有复活流程返回出生点，避免无限坠落。
- 移动和旋转后的箱子外观、承托与战斗遮挡使用其当前姿态。
- 角色接触和有效攻击能够向箱子传递有界的物理作用，箱子不因受力自动产生额外的伤害规则。

### R3 — 规则斜坡测试区

- 在现有庭院中增加一段约 20° 的斜坡并连接高台，入口与平地连通。
- 支持上下坡、斜向行走、坡面站立、坡面起跳 / 二段跳，以及走出高台边缘后下落。
- 在可行走坡面上移动稳定，不因坡面接缝抖动、无输入滑走或向上穿透。

### R4 — 连续起伏的小山

- 加入一座可见且可接近的小山，包含可行走缓坡、连续变化的坡度和山顶，不只是平面贴图或规则台阶。
- 小山外观和实际碰撞一致，能从平地走上缓坡、经过山顶、下山，也能从坡面起跳和落回坡面。
- 在过陡坡面上采用一致的坡度限制与下滑规则，不能沿近乎竖直的表面直接走上去。
- 小山和坡道的位置不占据玩家 / 练习敌人的出生点，保留原有战斗练习空间。

### R5 — 战斗、显示与暂停适配

- 保留现有两套武器、二段跳、身法和联动的触发语义；物理运动按当前碰撞结果结算。
- 遮挡、目标选择、近远程命中和击飞使用实际三维位置；箱子移动后遮挡也随之改变。
- 火炮落点能够选到可站立的箱顶、平台和地形表面，跃进遵循实际碰撞。
- 相机随实际海拔跟随，动画不重复叠加物理位移；原生和浏览器使用同一套模拟。
- 暂停时角色、动态箱子、重力、战斗与冷却一起停止，恢复不重放失效输入。

## Acceptance Criteria

- [x] AC1 / R1：角色跳到可达箱顶并稳定站立，平台上可以重新起跳；离开边缘后落回低处，不在空中恢复次数。
- [x] AC2 / R1：侧撞、顶头和高速闪避 / 跃进不会穿过实体，低顶下不能强行起身；玩家与敌人遵循相同接触规则。
- [x] AC3 / R2：角色能推动箱子，偏心作用能使其倾倒；至少两层箱子可稳定堆叠，支撑被移走后上方物体自然下落。
- [x] AC4 / R3：在斜坡上完成上下坡、斜行、停止、起跳 / 二段跳和高台边缘下落，接缝没有明显弹跳或穿透。
- [x] AC5 / R4：用户能从平地步行上小山、越过山顶下山，并在不同坡面起跳 / 落地；陡坡限制行为一致，地形外观与碰撞吻合。
- [x] AC6 / R5：不同高度和移动箱子遮挡下，锁定、攻击、锤子击飞 / 狙击、火炮跃进 / 旋斧及落点显示保持一致。
- [x] AC7 / R1–R5：暂停与恢复不改变已暂停的角色 / 箱子姿态或跳跃额度，不产生累积重力、冷却补算或输入重放。
- [x] AC8 / R1–R5：原有自动检查、针对新接触 / 支撑 / 地形的无窗口回归、WASM Clippy 和临时目录 Web 构建通过；真实浏览器另验收画面与操作体验。
- [x] AC9 / R2：低围墙可按实际高度跳越，场地外坠落后按复活流程恢复姿态与输入状态，没有不可见的无限高边界或无限坠落。

## Constraints

- 维持单 crate 和客户端 → 玩法 → 模拟依赖方向；物理权威属于模拟层。
- 保留任务开始前的入口卡片和二段跳未提交改动，详见 [基线与已确认决定](research/baseline-and-decisions.md)。
- 模拟仍使用固定 60Hz，保留显示插值和现有相机构图。
- 不启动或关闭用户开发服务；浏览器验证仅使用本次测试自建、结束后回收的临时 fixture。
- 未实现的设计只写在本任务目录，落地后再同步现有规范。
- 提交和推送需要用户明确授权，任务记录不自动提交。

## Out of Scope

- 流体、布料、软体、地形挖掘、物体破碎和角色布娃娃。
- 新关卡编辑器、联网 / 回滚系统和美术资产替换。
- 改写武器伤害数值、添加新技能或取消既有二段跳。
