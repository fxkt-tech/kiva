# 定时兵线、小兵AI与表现

## 来源与状态

属于[单中路总体方案](../11-07-single-lane-match/prd.md)。用户已要求继续，按父方案进入实施；提交/推送仍待后续明确授权。

## 验收要求

- [x] 开局立即生成首波，每方每波恰好3近战3远程，之后60/120/180秒出兵；时间边界和暂停恢复不重出/漏出。
- [x] 兵线沿唯一中路推进，优先接战敌兵，有限追击英雄，清敌后继续攻击基地。
- [x] 普通走路改善重叠但不新增硬卡位、不改冲刺/强制位移，近战和远程外观/射程/投递可区分。
- [x] 死亡根及子模型及时清理，已提交攻击继续快照生命周期，长局不能累积隐藏尸体或静默跳波。

依赖lane-map-match与lane-combat-foundation；此切片可用暂不决策的敌方英雄单独验收兵线。
