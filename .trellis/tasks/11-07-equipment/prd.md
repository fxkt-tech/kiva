## 目标

## 已知事实与采用范围

- 已有属性来源修正、不可变伤害/效果、技能权限和生命周期、角色选择与整局重开；138项旧测试必须保留。
- 装备主动不占用QWER，复用现有施法/目标/投递/伤害/控制/运动流程，六格各有主动冷却。
- 采用训练场直接装卸，不加入金币、商店或合成；已发送可选偏好问题，并在充分等待后明确此默认范围。
- 不扩展现有七属性以外的生命/法力上限或回复属性；装备不直接修改UnitStats。

## 需求

| 编号 | 需求 | 可观察结果 |
|---|---|---|
| R1 | 六格目录与实例分离 | 每单位最多6件；重复同种装备合法，来源/冷却互相独立；占用格不隐式替换 |
| R2 | 来源属性与原子装卸 | flat/percent通过属性模块生效，卸下只移除本实例，无逆向减法和残留；错误不改原状态 |
| R3 | 实际被动 | 首版OnBasicAttackHit附伤/控制，按格/被动索引稳定执行；不被技能/装备主动或被动伤害再次触发 |
| R4 | 独立主动 | 1–6或鼠标选装备，单位/地点/方向/自身目标按定义；角色与装备共用一套提交/中断/效果流程 |
| R5 | 身份和快照 | 主动意图锁装备实例；卸装取消本实例未提交前摇和未来引导，已提交弹丸/区域/冲刺和普攻被动快照保留 |
| R6 | 生命周期 | 死亡保留装备/加成；装备主动CD随固定步含死亡推进，重生不刷新；暂停冻结；整局重开清空装备 |
| R7 | 可用交互 | P或暂停菜单打开装配界面，暂停/释放捕获后装卸；占满、错误、无主动、冷却/控制状态清晰 |
| R8 | 展示与维护 | HUD六格、名称/加成/被动/主动说明来自Rust只读投影；144px无单位七属性和原四技能保持 |

训练装配每次穿戴创建新实例、主动从0CD开始；卸下销毁该实例。属性与被动按实例叠加，不实现唯一组或共享CD。
这属于训练场直接装卸语义；后续经济/平衡若需要唯一组、共享冷却或购回，需在装备模块扩展明确规则。

## 演示内容

9件：锋刃（攻击20）、灵巧短弓（攻速25%/攻距0.5）、法术典籍（法强30）、守护披甲（护甲25/魔抗20）、
疾行之靴（移速0.75）、霜纹护符（法强10，普攻命中12+10%AP魔伤及20%减速1s）、
束缚法珠（法强15，主动复用奥术禁制）、流风之刃（攻击10，主动流风步）、共鸣棱镜（法强20，主动共鸣）。
数值为本期演示配置，不新增技能效果或在战斗中按装备ID分支。
