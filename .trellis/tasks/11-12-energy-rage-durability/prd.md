## 实现方定的数值与细则

| 项 | 取值 | 说明 |
|---|---|---|
| 强化 E/Q 伤害倍率 | ×1.5 | 写在技能表每行 |
| 强化的触发 | 烈阳／月光满时下一次 E／Q 自动强化并清零 | 文档已无长按 |
| 弹反反击伤害 | 10 | 弹反成立即积累 1 点烈阳 |
| 烈阳积累粒度 | 每一次造成伤害的命中 1 点 | 范围技打中两个敌人是 2 点，三连发最多 3 点 |
| 暴怒技 | 进入暴怒状态本身，无额外攻击 | 文档只描述了状态 |
| 暴怒条 | 20 点在 20 秒内匀速耗尽 | 条的剩余量就是剩余时间 |
| 暴怒期间的能量 | E/Q 不消耗烈阳／月光，也不再积累暴怒 | 避免暴怒自我续杯 |
| 暴怒的自动联动 | 联动窗口成立的下一步自动准入，等同按下 Tab | |
| 技能耐久消耗 | E、Q 各 10；联动 0；普攻 1 | 联动是前置技能的延续 |
| 耐久耗尽 | 不拒绝当前动作；动作结束且联动窗口关闭后自动换到下一组 | 不打断已承诺动作和联动 |
| 耐久恢复 | 被自动换下的那组立即回满 | “如此循环”需要它能再被换回 |
| Z 手动换组 | 不恢复耐久 | |
| 倒地复活 | 三种能量清零、暴怒结束、耐久回满 | 与冷却、耐力一致 |
| F2 换敌人 | 保留能量与耐久 | 与耐力一致 |
