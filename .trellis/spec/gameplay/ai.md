# 自主兵线与英雄战术

## 1. 范围与所有权

适用于`src/gameplay/ai/`、`tests/minions.rs`、`tests/hero_ai.rs`及模拟普通移动的`SoftAvoidance`。
模式构造、波次和终局见[match.md](match.md)，伤害、预检与恢复见[模拟基础](../simulation/combat-foundation.md)。
AI只拥有私有Brain记忆并提交`UnitCommand`，不写HP、法力、CD、位置或战斗动作。

## 2. 接口与观察

`AiPlugin`独立安装于`GameplayPlugin`之后，在`GameplaySet::Decisions`、完整`SimulationSet::Step`之前运行。
`GameplayPlugin`自身不隐式启动战术，规则测试可单独安装它。

控制来源使用模式`Controller::{Human,HeroAi,MinionAi}`；角色使用`UnitRole`，不能凭控制来源推断单位类别。
每名单位首次观察/新生命等待12tick，之后每12tick决策一次，每次最多一条指令。暂停、Waiting、终局、模式错误不推进决策。

观察快照按Entity稳定排序，再按决定者自身阵营通过team_can_see过滤，只含可见存活单位当前生命身份、位置、上一模拟步位移、角色、阵营、碰撞和生命。
可见弹丸使用当前位置/速度；技能和装备候选读取决定者自己的实际装配、资源及`preview_cast`。
不读取敌人的CD、输入队列或未来路径。伤害评分复用`DamageSpec::estimate_damage`，最终命中仍由模拟裁决。

## 3. 目标与命令契约

- Brain保存`UnitLifeRef`，每次复核当前生命；死亡/复活不能沿用旧生命目标。
- 同一目标不重复发送`AttackTarget`；目的相差不足0.4的`MoveTo`不重复提交。
- 英雄保留普通前摇、施法与引导，仅紧急撤退可打断；已提交Dash期间不提交新操作。
- 小兵保留攻击准备；同级目标保持稳定，准备完成后可由英雄目标转向优先级更高的小兵。
- 显式检查已知控制权限；施法全部先经共享只读预检，提交时仍重新验证，不把预检当授权。
- Brain不保存第二套攻击/技能计时，后摇走位不会刷新模拟独立攻击间隔。

## 4. 小兵与普通移动

目标优先敌兵、附近英雄，清空后向敌基地推进。获取距离5.5、保持距离8，目标横向位置受中路半宽加1约束。
无目标时按实际中路投影进度构造量化前进点，三列沿`WaveMember.slot`派生横向位置；不维护与真实位置脱节的航点计数。
进入实际攻距加半径附近后攻击基地；基地技能免疫仍由模拟保证。

`simulation::SoftAvoidance`是普通行走的显式标记，由小兵AI装配。移动系统在写任何位置前收集稳定排序的邻居快照，
只对Ready且沿路线行走的标记Actor施加有界侧向分离，仍经过地图sweep。
它不是单位硬碰撞：不推开停步/射程内前摇单位，不把英雄变成阻挡，不改变Dash/强制位移终点。
可选侧移撞墙时尝试原始路线前进sweep；侧避让失败不能导致有效窄路永远反复清路线。

## 5. 英雄战术与技能语义

私有战术为推进、交战、撤退、恢复、守家。通常跟随己方最前兵后2.4，没兵时推进至中场；
己方基地6.5范围内出现敌Actor提高守家评分。选择目标有30tick承诺，新目标须明显更优才切换。

生命低于25%撤退；生命低于60%且局部敌众我寡也撤退，恢复至少75%后回线。
恢复只由模式调用受限模拟入口。英雄只决定回己方安全点，不直接回血/补蓝/传送。

追击英雄共用`Pursuit`：12视距、目标在中路半宽加2内、起追位置6距离绳、离普攻射程最多240tick。
放弃后180tick不重新追英雄，主动回兵线；普通攻击、进攻Dash和其他进攻技能使用相同目标资格。
仍在射程内可持续交战；当前空间绳不会因每次普攻重新刷新。

技能不按QWER或内容ID分类，候选来自当前`AbilitySlots`和装备实例主动：

| 语义 | 候选与边界 |
| --- | --- |
| Enemy/Direct | 合法Actor目标，伤害和未重复控制增加价值 |
| Direction/Projectile | 按当前速度有限前导，最多0.7秒/3距离；按同样有限外推估计第一碰撞，兵线能挡弹 |
| Point/Area | 结合前摇/延迟的有限预测，计算范围覆盖价值 |
| SelfCast/Area或Channel | 只在当前范围有敌人时使用；长引导还要求生命和威胁许可 |
| Dash | 撤退朝己方安全点且威胁不增加；进攻仅对当前可追击残血英雄、有生命优势且落点威胁有限时使用 |

新复合执行在`compound_spells.rs`按定义语义生成候选：Line优先连接已落地己方来源的Standard，Standard落地前等待；
Shield按可见威胁与血量使用，Empower只在真实专注充足时激活，Leap仅锁合法Hero且落点安全。
Volley计算真实扇面收益，Arrow首撞过滤Hero，不能把小兵当成挡大箭的屏障。
Scout只侦察地图上的未知通道或前进方向，不用隐藏敌军坐标瞄准；揭示后下一次观察才能加入进攻候选。
对象激活/到期通过BattlefieldObject读取，不能从技能CD反推对象是否已经落地。
AI链接突进中保留原运动，不提前用Leap/新Dash/新链接覆盖沿途击飞，仍可使用盾/旗等非运动技能；人类施法权限不受这个战术选择限制。
普通进攻Dash、旗拉和Leap共用offensive_landing_allowed：仅据同一可见快照计算落点净风险及相对当前的增量，
友军支援按真实生命比例计入并排除本人/基地；满血也不能绕过绝对风险2.3或增量1.5门。
所有候选继续经过同一preview_cast与有限追击资格，重施拆墙按自己实际机制状态处理。

弹丸规避依据已观察的当前速度/短时相交，5Hz反应，普通攻击冷却期间可安全后退拉距离。
预测不会读取玩家未来停止/转向，实际技能仍可躲避。

## 6. 验证与边界

`cargo test --locked --test minions --test hero_ai`覆盖真实会兵、稳定长前摇、追击回线、清兵后打基地、
旧/新生命、小兵清理、普通避让、静态窄廊、Dash/强制终点、实际不同技能装配与装备主动、资源/控制、
受伤回家恢复回线、守家、有限方向预判以及有限追击与攻守Dash。

30分钟长跑显式执行：

```sh
cargo test --locked --test minions half_hour_real_waves -- --ignored --nocapture
```

该场景只提高基地HP延长对局，真实生成每分钟双方3+3兵、运行敌方英雄AI并正常战损；
持续至108150tick，完成第31波的最后一对；在每个slot到期时观察当步双方新根并累计372个唯一身份，
不要求早先slot在整波排放完成时仍存活。检查无死兵残根、实体/效果峰值及重开回收，不跳波、不删活兵或设置隐形人口上限。
隔离AI战术的测试先通过真实固定步排完开局150tick，再清兵建立公开单位夹具；英雄在准备期间为Human，
切回HeroAi后才开始首次观察，不能改写私有待发状态或倒拨SimulationTick。

## 7. 错误与正确

错误：每次决策重发MoveTo取消自己的普攻；为追残血单独扫描Dash目标，绕过普攻的追击绳。

正确：稳定生命目标、保留承诺、对所有进攻候选共用追击资格；模拟继续唯一拥有战斗时钟和位置。

错误：AI直接扣血，或用隐藏玩家CD和未来命令保证完美闪避/命中。

正确：读取当前可见事实做有上限预测，通过相同公共命令和预检进入权威结算。
