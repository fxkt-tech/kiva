# 跨层思考指南

项目规范入口：[../index.md](../index.md)。以下指南辅助检查，不替代真实代码和任务方案。

- [跨层检查](cross-layer-thinking-guide.md)：模拟接口变化时找齐输入、内容、HUD 和测试的使用者。
- [复用检查](code-reuse-thinking-guide.md)：先搜索已有模型和行为，避免重复实现计算或流程。

Kiva 的跨层改动按以下数据流核对：

`内容定义 → 模拟构造 → 指令/动作/结算 → 只读投影 → Web DOM / 三维表现 → 浏览器断言`。

修改字段或数值规则前使用 `rg` 搜索所有使用者；用无窗口测试验证规则，用浏览器测试验证交互与投影。
