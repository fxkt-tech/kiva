# 跨层检查

数据流：Level → CollisionWorld / 视觉几何；设备输入 → ViewYaw / MoveIntent → FixedUpdate Body → 插值模型 → 跟随相机。

- 唯一写入者是谁？客户端有没有改权威位置，玩法有没有依赖窗口？
- 世界 x/z、CSS 像素、设备像素和秒是否混用？
- 输入是否在固定步前只消费一次？显示帧零次 / 多次固定步是否仍成立？
- 角色和相机是否共用同一插值结果与朝向？构图是否用真实投影验证？
- Esc / 失焦 / 捕获失败后会不会遗留方向、旧按键或鼠标累计？
- Web 桥是否在 WASM 前安装？启动错误能否向晚订阅入口重放？
- 内容、模拟、客户端和普通测试是否同步更新？

先用 rg 找全调用方；规则无窗口测试，输入桥 Node 测试，浏览器画面和手感单独验收。
